什么是 Broadband Port Availability？为什么申请 Fibre 时它很重要？

✨ NetBijak AI 智能摘要

在申请家用光纤宽带时，许多消费者常混淆光纤覆盖范围与端口可用性这两个概念。即使你的居住大楼处于ISP的覆盖范围内，也并不代表能够立即安装，因为网络接入设备可能已达到容量上限，即所谓的端口已满。光纤基础设施的容量并非无限，尤其在公寓等高层住宅中，这种资源受限的情况更为常见。如果遇到端口不足，部分运营商会提供预约排队机制，或通过临时提供移动宽带作为过渡方案。因此，在申请前确认地址的实际可安装性至关重要，建议消费者不要仅参考覆盖图，而是通过详细的地址查询来获取最终的安装可行性确认。如果首选的运营商暂无端口，建议对比其他品牌，以确保能顺利开通所需的宽带服务。

如果你申请 Fibre Broadband 时被告知 “Port Full”，意思通常不是你家完全没有 Fibre，而是目前负责连接你单位的 Fibre 网络没有可用容量。

真正重要的问题不是“哪一家 ISP 还有配套”，而是：你所在地区有没有另一套 Fibre 网络可以申请。

什么是 Fibre Port？

简单来说，Fibre Port 是 Fibre 网络为你的住宅提供连接时所需要的可用网络容量。

Fibre Infrastructure 通常会经过类似 Distribution Point（DP） 的设备，再分配连接到附近的住宅、单位或建筑物。

所以你可能会遇到：

状态意思
Port Available有可用容量，可以申请安装
Port FullFibre Infrastructure 已经存在，但目前没有可用容量
No Fibre Infrastructure该地点目前没有相关 Fibre 网络

这也是为什么 “楼下邻居有 Fibre”不代表你的单位一定还有 Port。同一栋楼已经接入 Fibre，并不代表 DP 或相关网络设备还有空余容量。

马来西亚 Fibre Broadband 有一个容易搞错的地方

ISP 品牌不一定等于实际铺设 Fibre 的网络。

例如 Maxis 官方说明，其 Home Fibre 大部分连接使用 TM HSBB wholesale network，同时 Maxis 也拥有自己的 Fibre 网络，并通过其他网络合作伙伴提供服务。

这意味着：

Unifi Port Full → 换去另一家 ISP，不一定能够解决问题。

如果另一家 ISP 在你这个地址也是使用同一个 underlying network，那么真正造成 Port Full 的网络容量问题可能仍然存在。

所以申请之前，应该问清楚：

“这个配套在我的地址使用的是哪一个 Fibre network？”

而不是只问：

“你们有没有 Fibre？”

如果一个 Fibre Network Port Full，先检查其他网络

如果 TM-based Fibre 没有 Port，可以看看你所在的地址有没有其他 Fibre Infrastructure。

例如：

TIME

TIME Fibre Network

TIME 表示其 Home Fibre 使用自己拥有和运营的 100% Fibre Network。

因此，如果你原本申请的网络没有 Port，而你的地址又有 TIME Coverage，这才是真正意义上的换网络，而不只是换 ISP 品牌。

Allo

Allo 官方网站

Allo 是 TNB 旗下公司，并运营 open-access full-fibre infrastructure，部分地区可以通过不同的 Broadband Provider 使用这套网络。

所以遇到 Port Full 时，应该检查的是：

你的地址有没有第二套 Fibre Infrastructure，而不是只看第二个 ISP 品牌。

如果其他 Fibre 也没有 Port 呢？

这时候基本上只剩两个现实选择：

1. 等网络增加容量

你可以向 ISP 查询：

  1. Port Full 是暂时性还是长期性？
  2. 是否已经计划增加容量？
  3. 有没有预计的 upgrade / installation timeframe？

如果 ISP 可以提供比较明确的时间，你可以选择等待。

但如果只是告诉你 “请等候，我们无法提供时间”，就不要把它当成有确定安装日期。

Port Full 没有一个所有住宅都适用的固定等待时间。 实际上取决于当地 Fibre Infrastructure、网络规划以及额外容量什么时候完成。

急着要 Internet？可以先用 4G / 5G

如果你现在就需要 Internet，例如：

  1. 搬新家
  2. WFH
  3. 小孩上网课
  4. 暂时租屋
  5. 等 Fibre 安装期间

可以先考虑 4G / 5G Home Internet。

一个比较直接的例子是 Maxis 的 Fibre Pre-Installation Offer。

Maxis 目前为部分在申请 Fibre 时遇到 Port Full 或即将覆盖地区的新客户提供 Maxis Home 4G WiFi 138，之后 Fibre 有供应时再升级到 Maxis Home Fibre。官方目前列出的优惠是 RM50 × 24个月 rebate，符合条件的客户最高 24 个月支付 RM88/月。

不过 4G/5G 的实际速度还是会受到：

  1. Mobile Coverage
  2. 用户数量
  3. 网络拥塞
  4. Router / Device

影响，所以它比较适合作为 等 Fibre 期间的过渡方案，而不是默认等同于 Fibre。

可以要求 ISP 安装新的 DP 吗？

可以向 ISP 提出要求，但 DP 属于网络基础设施，不是普通的个人安装项目。

是否增加或升级 DP，一般需要由负责该 Fibre Infrastructure 的网络运营商根据：

  1. 当地网络规划
  2. 现有容量
  3. 新增需求
  4. 建设成本
  5. 区域发展

等因素决定。

所以一个用户通常可以 提出需求或让 ISP 记录需求，但不能把增加一个新的 DP 当成普通 Fibre Installation 一样要求立即安装。

NetBijak’s Take

遇到 Port Full，不要第一时间只想着换 ISP。

先查清楚 是哪一个 Fibre Network 没有 Port。如果当地还有 TIME、Allo 或其他不同 Fibre Infrastructure，换到另一套网络才有实际意义；如果没有其他 Fibre，就在“等待容量升级”和“暂时使用 4G/5G”之间做选择。

简单说：换 Network，比单纯换 Brand 更重要。
