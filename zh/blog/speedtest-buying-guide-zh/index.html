宽带测速结果

✨ NetBijak AI 智能摘要

宽带测速结果并不总是与配套标示的理论速度完全一致，这受限于多种硬件及环境因素。一般情况下，有线连接测得的配套速度达到90%即可视为正常范围，这是评估网络质量的重要参考。若发现测速长期停留在90-100Mbps左右，很可能是由于路由器端口、网线或设备不支持千兆传输造成的物理瓶颈。建议在排查线路问题时，优先使用千兆网线进行有线测速，而非依赖信号易受干扰的无线网络。此外，理解Mbps与MB/s的单位差异，能帮助用户更准确地解读下载速度。如排除所有本地硬件限制后速度仍不达标，请记录多次测试结果并及时联系运营商进行处理。

如何看懂你的宽带测速结果

宽带测速显示的是你在测速当下的网络表现。要判断速度是否正常，不能只看一个数字，还要对照你订购的配套速度，以及测速时使用的是 WiFi 还是有线连接。

你的宽带应该测到多少速度？

测速结果不一定每次都刚好等于配套标示的速度。路由器、网线、设备、WiFi 环境以及网络状况，都可能影响最终结果。

如果是经过正确设置的有线测速，可以先用配套速度的 90% 作为一个参考：

宽带配套90% 参考值
100Mbps90Mbps
300Mbps270Mbps
500Mbps450Mbps
1Gbps900Mbps
2Gbps1.8Gbps

这个 90% 数值与马来西亚宽带服务质量要求有关。不过，它应该被视为评估测速结果的参考，而不是保证每一次测速都会得到完全相同的数字。

资料来源： 马来西亚通讯及多媒体委员会（MCMC）

为什么测速比我的宽带配套慢？

测速较低，并不代表 ISP 一定有问题。

常见影响因素包括：

  1. WiFi： 路由器距离、墙壁、无线干扰、网络拥堵以及设备本身都会影响速度。
  2. 路由器： 较旧的路由器，或者只有 100Mbps LAN Port 的设备，会限制高速宽带。
  3. 网线： 网线规格或损坏情况可能限制有线连接速度。
  4. 电脑或手机： 网络卡、WiFi 芯片以及设备性能也会影响测速。
  5. 其他设备： 下载文件、云端备份、串流或其他设备正在使用网络时，测速结果会降低。
  6. 测速服务器： 不同测速服务器的网络路径和当时负载不同，结果也可能有所差异。

如果你使用的是 Fibre Broadband，并且想判断线路本身有没有达到合理速度，最好使用电脑直接连接路由器的 Gigabit Ethernet 进行测速。

为什么我的 300Mbps 只有 90Mbps 左右？

如果你订购的是 300Mbps、500Mbps 或更高速的配套，但测速长期停留在 90–95Mbps 左右，就值得检查。

其中一个很常见的原因，是你的本地网络某个环节只有 100Mbps。

例如：

  1. 100Mbps Ethernet Port
  2. 老旧的网络卡
  3. 不合适或损坏的网线
  4. 100Mbps Switch
  5. 只有 100Mbps 的 Router LAN Port

如果电脑与路由器之间的 Ethernet 连接只协商到 100Mbps，那么即使你的 Fibre 配套是 300Mbps 或 500Mbps，也无法通过这条连接跑出更高的速度。

在投诉 ISP 之前，先检查电脑显示的 Ethernet Link Speed，以及路由器和网络卡是否支持 Gigabit Ethernet。

测速应该用 WiFi 还是网线？

如果你想检查 Fibre 线路本身的表现，建议使用 Ethernet 有线连接。

WiFi 测到的不只是宽带线路，还包括：

  1. 路由器的无线性能
  2. WiFi 信号强度
  3. 周围无线干扰
  4. 使用的 WiFi 频段
  5. 手机或电脑本身的无线规格

例如，你的 Fibre 是 500Mbps，但手机通过 WiFi 只测到较低速度，并不能单凭这个结果判断 ISP 没有提供 500Mbps。

WiFi 测速适合了解你在手机、笔记本电脑等设备上的实际使用速度；如果要排查 Fibre 线路，则应该优先使用有线测速。

Mbps 和 MB/s 有什么不同？

宽带配套通常使用 Mbps（Megabits per second），但一些下载软件会使用 MB/s（Megabytes per second）。

1 Byte = 8 bits，所以理论换算如下：

  1. 100Mbps ≈ 12.5MB/s
  2. 300Mbps ≈ 37.5MB/s
  3. 500Mbps ≈ 62.5MB/s
  4. 1Gbps ≈ 125MB/s

这只是单位换算，实际下载速度还会受到网络开销、下载服务器能力以及其他网络因素影响。

例如，300Mbps 宽带下载文件时显示约 35MB/s，并不代表只有 35Mbps。换算后大约相当于 280Mbps，再考虑正常的网络开销，这个结果可能是合理的。

什么时候应该联系 ISP？

如果排除了设备和本地网络的问题，而有线测速仍然明显低于应有水平，就可以考虑联系 ISP。

联系客服前，可以先：

  1. 用 Gigabit Ethernet 将电脑直接连接到路由器。
  2. 确认电脑网络卡和网线支持你的配套速度。
  3. 暂停大型下载、云端备份及其他大量占用网络的活动。
  4. 连续进行几次测速。
  5. 如果测速工具提供多个服务器，可以尝试其他服务器。
  6. 记录测速结果以及测速时间。

如果在这些条件下，有线测速仍然持续偏低，这些记录会比单次 WiFi 测速更有参考价值，也方便你向 ISP 反映问题。

一次较低的 WiFi 测速结果，并不足以证明 Fibre 线路出现故障。
