家用电器干扰 Wi-Fi：微波炉、Bluetooth 与无绳电话

✨ NetBijak AI 智能摘要

当微波炉启动时家里Wi-Fi突然变卡，这通常不是宽带线路问题，而是2.4GHz频段受到干扰所致。由于微波炉、蓝牙设备和各种智能家居都使用2.4GHz频段，该频段极易出现信号拥挤与传输冲突。为了提升网速稳定性，建议将路由器移离微波炉，并尽可能让手机和电视等设备改用5GHz或6GHz频段。对于IoT设备，可以保留在2.4GHz频段，但要避免所有设备挤在一起。通过正确的摆位和频段分流，你无需更换宽带配套也能显著改善网络体验。

微波炉一启动，客厅 Wi-Fi 就突然变得不稳定，不一定是宽带线路出了问题。很多时候，真正出问题的是 2.4GHz 无线环境。

Wi-Fi、Bluetooth，以及部分旧款无绳电话都可能使用或影响这一频段。微波炉工作时，也可能对附近的 2.4GHz Wi-Fi 造成干扰。

为什么 2.4GHz 特别容易拥挤

2.4GHz 并不是 Wi-Fi 独占的频段。

Bluetooth 使用 2.4GHz ISM 频段，而且需要与 Wi-Fi 和其他无线设备共同使用频谱。当不同无线传输发生冲突时，就可能出现封包损失和重传。(Bluetooth SIG)

Cisco 也把微波炉、2.4GHz 无绳电话、Bluetooth 设备，以及附近其他 Wi-Fi 网络列为可能影响 2.4GHz WLAN 的干扰源。(Cisco)

现在的家庭如果同时有这些设备，2.4GHz 很容易变得拥挤：

  1. Smart Plug
  2. 智能感应器
  3. IoT 设备
  4. Bluetooth 音箱、键盘、滑鼠
  5. 无线摄像头
  6. 邻居的 Wi-Fi
  7. 部分旧款 2.4GHz 无绳电话

所以，即使 ISP 给到的宽带速度正常，家里的 2.4GHz Wi-Fi 仍然可能不稳定。

为什么微波炉会影响 Wi-Fi

家用微波炉通常在 约 2.45GHz 工作，正好接近 2.4GHz Wi-Fi 所使用的频率范围。Cisco 的无线网络资料也指出，微波炉可能对 2.4GHz WLAN 造成干扰。(Cisco)

正常的微波炉会利用金属腔体、门板等结构把微波能量限制在机器内部。美国 FDA 规定，家用微波炉的泄漏量在距离炉体约 2 英寸的位置测量时，不得超过 5mW/cm²。(U.S. FDA)

问题在于，Wi-Fi 接收器接收到的无线信号本身可能已经很弱。

例如：

厨房微波炉 → 开放式饭厅 → 客厅 Wi-Fi 设备

当微波炉启动后，额外的 RF 干扰进入 Wi-Fi 接收器，可能导致封包错误增加、重新传输次数上升，最终出现：

封包错误 ↑ → 重传 ↑ → 实际速度 ↓ → Wi-Fi 不稳定

这时光纤连接本身可能完全正常，真正受影响的是屋内的无线连接。

最有效的办法：先处理摆位

遇到微波炉干扰，第一反应不应该只是一直换 Wi-Fi Channel。

更直接的方法是 拉开微波炉与 Wi-Fi 设备之间的距离。

不要把路由器放在微波炉旁边

不要把主路由器或 Mesh Node 放在厨房微波炉旁边，也不要把它们塞进紧邻微波炉的橱柜里。

更合理的布局是：

厨房

微波炉

↓

墙壁 / 物理隔离

↓

客厅

Wi-Fi Access Point

墙壁和建筑材料会削弱 RF 信号。Cisco 的 RF 资料也把混凝土、墙体和金属列为会造成无线信号衰减的材料。(Cisco)

这里的目标不是把微波炉“封起来”，而是不要让 Wi-Fi 设备长期处在干扰较强的位置。

把能用 5GHz 的设备移过去

手机、Laptop、Smart TV 等支持双频的设备，优先连接 5GHz。

Cisco 指出，2.4GHz 更容易受到微波炉、Bluetooth 和部分无绳电话等设备影响，而 5GHz 所受的这类干扰较少。(Cisco)

因此，如果你的客厅就在厨房旁边，可以这样分配：

设备建议连接
手机 / Laptop5GHz 或 6GHz
Smart TV5GHz / Ethernet
2.4GHz-only Smart Plug2.4GHz
智能感应器2.4GHz
经常受到微波炉影响的设备5GHz / 6GHz（支持的话）

2.4GHz 适合留给确实需要较远覆盖范围的 IoT 设备，不需要让所有设备都挤在这个频段。

Bluetooth 也会造成干扰吗？

会，但情况不完全一样。

Bluetooth 同样使用 2.4GHz ISM 频段，不过它本身就是为了与其他无线系统共存而设计，并使用跳频等机制降低持续干扰。(Bluetooth SIG)

因此，家里只有一个 Bluetooth Mouse 或一台 Bluetooth Speaker，通常不会单独造成严重的 Wi-Fi 掉线。

真正需要注意的是 大量 2.4GHz 设备同时工作。

例如一间 Smart Home 同时有几十个 IoT 设备、多个 Bluetooth 装置和附近大量邻居 Wi-Fi，2.4GHz 的竞争自然会更明显。

无绳电话一定会干扰 2.4GHz 吗？

不一定。

部分旧款无绳电话确实使用 2.4GHz，Cisco 也将它列为可能的 WLAN 干扰来源。(Cisco)

但不能看到“无绳电话”就直接认定它会影响 2.4GHz Wi-Fi。不同技术使用的频率不同，因此应该先看设备规格。

要不要换 2.4GHz Channel？

可以尝试，但不要把它当成万能解决方案。

Apple 目前建议 2.4GHz 使用 20MHz Channel Width，因为较窄的 Channel Width 在拥挤的无线环境下通常更有利于稳定性；同时，在路由器支持的情况下可以让系统自动选择 Channel。(Apple Support Malaysia)

处理微波炉干扰时，可以按这个顺序：

1. 把路由器 / Mesh Node 移离微波炉。

2. 手机、Laptop、TV 改用 5GHz 或 6GHz。

3. 2.4GHz 保持 20MHz。

4. 如果问题仍然存在，再测试其他 2.4GHz Channel。

如果微波炉造成的干扰范围较广，仅仅换一个 Channel 未必能够彻底解决。

怎么确定真的是 Wi-Fi 干扰？

不要凭感觉判断。

测试 1：2.4GHz

让手机或 Laptop 固定连接 2.4GHz，并放在平时最容易出问题的位置。

开启微波炉，观察 Wi-Fi 是否马上恶化。

测试 2：5GHz

同一个设备改接 5GHz，再重复测试。

如果：

2.4GHz 一开微波炉就不稳定

5GHz 基本正常

那就很有可能是 2.4GHz 无线干扰，而不是 ISP 光纤线路的问题。

测试 3：Ethernet

再用网线连接电脑到路由器。

如果：

Ethernet 正常

5GHz 正常

只有 2.4GHz 出问题

就更应该从 Wi-Fi 环境找原因，而不是一直投诉“宽带很慢”。

不要自己给微波炉加铝箔屏蔽

“金属可以挡微波，所以拿铝箔包起来”这个想法听起来合理，但不应该这样处理家用微波炉。

微波炉的机身、门板、密封结构、散热和安全联锁都是按照整套设计运行。不要自行修改机身，也不要用金属板或铝箔做 DIY 屏蔽罩。FDA 对微波炉的门和安全联锁都有相关要求。(U.S. FDA)

真正应该做的是 拉开距离、改变 Wi-Fi 摆位，或者把设备移到 5GHz / 6GHz。

NetBijak’s Take

微波炉导致 2.4GHz Wi-Fi 不稳定，并不代表你的 fibre broadband 有问题。先处理 设备摆位和频段分流，通常比不断换 Channel 更实际；2.4GHz 留给需要覆盖范围的 IoT，手机、Laptop 和 TV 则尽量使用 5GHz 或 6GHz。
