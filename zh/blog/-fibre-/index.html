正确测试 Fibre 网速的方法

✨ NetBijak AI 智能摘要

怀疑家中网速不理想时，切勿仅凭手机WiFi测试结果下结论，应优先使用LAN网线将电脑直连路由器进行有线测速。测试时需确保网线为Cat5e或Cat6标准，并检查电脑接口是否支持千兆传输，以避免因硬件瓶颈导致的100Mbps速度封顶。建议在关闭其他后台应用的情况下进行多次有线测试，若连续结果明显低于MCMC规定的90%服务质量基准，则可视为网络供应商的问题。在确定有线速度正常的前提下，若WiFi测速依然缓慢，则应排查路由器位置或覆盖范围，而非盲目升级宽带配套。向客服报修时，请提供多次有线测速截图作为证据，这样能更有效地让技术人员跟进处理。正确的方法能帮助你准确区分究竟是运营商线路故障，还是家庭内部网络配置的问题。

测 Broadband Speed，不要直接拿手机连 WiFi 跑一次 Speedtest 就下结论。要判断 Fibre 本身有没有问题，第一步应该是用 LAN Cable 直接连接 Router，再进行多次测试。

NetBijak 测速方法：先测 Fibre，再测 WiFi

最简单的顺序是：

LAN 测试 → 重复测试 → 对比配套速度 → 再测试 WiFi

这样才能分清楚到底是 ISP 的 Fibre 有问题，还是你家里的 WiFi 有问题。

CelcomDigi 建议用户通过 LAN Connection 检查实际 Broadband Speed，Unifi 也建议使用 Wired Connection 进行速度测试。 CelcomDigi Fibre Speed Guide · Unifi Speed Test FAQ

1. 先插 LAN Cable，不要急着怪 ISP

要测试 Fibre 本身，最好把 Laptop 或 PC 直接接到 Router 的 LAN Port。

Unifi 在测速指引中建议，高速 Broadband 应使用合适的 Ethernet Cable，以及具备 Gigabit Ethernet 的电脑，同时在测速时断开其他设备和关闭正在占用带宽的应用程序。 Unifi Speed Test FAQ

如果你现在还在使用很旧的网线，建议至少换成 Cat5e 或 Cat6 再测。

电脑本身也一样重要。

如果你的 Laptop 是通过旧款 USB-to-Ethernet Adapter、Docking Station，或者只有 100Mbps Fast Ethernet 的 LAN Port，那么就算你订的是 500Mbps 或 1Gbps Fibre，也可能永远跑不上去。

2. 小心最常见的「100Mbps 封顶陷阱」

这个问题其实很好认。

如果你订的是 300Mbps、500Mbps 或 1Gbps，但连续几次有线测速都卡在 90–95Mbps 左右，先别急着打电话骂 ISP。

先检查自己的硬件。

网线问题

旧 Cable 或品质不佳的 Cable 可能成为瓶颈。最简单的方法，就是换一条确认正常的 Cat5e 或 Cat6 再测试。

LAN Port / Adapter 问题

检查 Laptop、USB-to-Ethernet Adapter、Docking Station 或 Router LAN Port，目前到底是以：

100Mbps

还是：

1000Mbps / 1Gbps

连接。

如果 Ethernet Link 只协商到 100Mbps，那么你的 300Mbps、500Mbps Fibre 根本没有机会发挥完整速度。

所以：

500Mbps Fibre 测到 92Mbps，不一定是 Fibre 有问题。

先检查是不是你的 Hardware 把速度锁死在 100Mbps。

3. 大马用户一定要知道的 MCMC 90% 标准

这组数字值得记下来。

MCMC 针对 Wired Broadband Access Service 的 Mandatory Standards，对 Fibre Throughput 设有 90% subscribed speed 的服务质量基准；相关要求是 Fibre 的 Download 和 Upload Throughput，应达到订购速度至少 90%，并在至少 90% 的时间达到该水平。 (MCMC Industry Performance Report)

简单换算：

500Mbps 配套 → 450Mbps

300Mbps 配套 → 270Mbps

100Mbps 配套 → 90Mbps

但是这里不要误会。

“90% Rule” 并不是说你每一次 Speedtest 都必须刚好达到 90%。

这是一个针对服务表现的 QoS 标准，并不是保证你 Laptop 每一次测速都会显示完全一样的数字。 (MCMC Industry Performance Report)

所以一次测速只有 200Mbps，并不能单凭这一张截图就证明 ISP 违反标准。

但如果你的 LAN 有线测速连续多次明显低于这个水平，同时你已经排除网线、LAN Port、Adapter、电脑和其他网络使用情况，那么你就有更充分的理由向 ISP 提交技术投诉。

4. 不要只测一次

一张 Speedtest Screenshot 不能代表全部。

建议至少测 3 次，最好选择不同时间进行。

测速前先关闭：

  1. Netflix / YouTube
  2. Game Download
  3. OneDrive / Google Drive Backup
  4. VPN
  5. Windows Update
  6. 其他大量占用 Bandwidth 的应用

Unifi 建议测速时减少其他设备及网络流量；CelcomDigi 也建议通过 LAN 来检查订购的实际速度。 Unifi Speed Test FAQ · CelcomDigi Fibre Speed Guide

连续三次都低，才更值得认真追查。

5. LAN 测完，再测 WiFi

有线测速确认之后，再拿手机或 Laptop 测 WiFi。

这一步是为了回答一个非常重要的问题：

到底是 Fibre 慢，还是你家的 WiFi 慢？

Maxis 提醒用户，WiFi Speed 会受到 Router 距离、墙壁等因素影响；CelcomDigi 也提到 WiFi Frequency、连接设备数量和 Router 放置位置都会影响实际测速结果。 Maxis Home WiFi Speed Test · CelcomDigi Fibre Speed Guide

例如：

500Mbps Fibre + LAN：480Mbps

500Mbps Fibre + WiFi：120Mbps

这种情况下，不应该第一时间叫 ISP 帮你升级到 1Gbps。

因为你的 Fibre 本身可能已经正常，真正的瓶颈可能在 WiFi Coverage、Router、手机或 Laptop。

6. 报修不要只说「Internet Slow」——给证据

如果真的要向 Unifi、Maxis 或其他 ISP 开 Ticket，最没用的一句话就是：

“Internet saya slow.”

客服每天都会收到这种投诉。

更有效的方法是准备 3 张有日期的 Wired Speed Test Screenshot，记录：

  1. 测试日期和时间
  2. Download Speed
  3. Upload Speed
  4. 测试方式：LAN
  5. 使用的 Laptop / PC
  6. Ethernet Adapter 或 LAN Port

可以使用 Speedtest by Ookla 等测速工具；CelcomDigi 官方也建议使用 Speedtest by Ookla 检查 Broadband Performance。 CelcomDigi Internet Speed Guide

然后直接这样跟客服说：

“I performed three wired LAN speed tests and the results are consistently below 90% of my subscribed Fibre speed. Please check the line and escalate this as a technical fault.”

比单纯说“我的 Internet 很慢”有效得多。

Show Proof, Not Excuses。

什么时候应该正式投诉 ISP？

满足下面两个条件，就值得开 Technical Ticket：

第一：你的 LAN Speed 连续测试都明显偏低。

第二：你已经排除了网线、LAN Port、Adapter、电脑和 Background Traffic。

这时记得保留 Speed Test Screenshot 和 Ticket Number。

Unifi 有 EasyFix 进行连接检测；Maxis 和 CelcomDigi 也提供 Fibre / Home Network 的 Troubleshooting 和支援渠道。 Unifi Support · Maxis Home Fibre Support · CelcomDigi Fibre Support

NetBijak’s Take

别因为手机 WiFi Speedtest 只有 150Mbps，就马上把 500Mbps Fibre 升级成 1Gbps。

先做一次正确的 LAN Speed Test。

如果 LAN 已经接近你的 subscribed speed，而 WiFi 很慢，升级 Fibre 很可能只是多花钱，却没有解决真正的问题。

而当你的有线测速长期明显偏低时，MCMC 的 90% benchmark 就是你和 ISP 沟通时非常有用的参考数字。 (MCMC Industry Performance Report)
