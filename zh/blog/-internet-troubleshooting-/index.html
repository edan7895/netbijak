为什么我的 Internet 很慢？马来西亚家庭宽带 Troubleshooting 指南

✨ NetBijak AI 智能摘要

网速慢并不一定意味着宽带套餐不够快，实际体验往往受Wi-Fi覆盖、路由器位置、设备能力及网络干扰等因素影响。在考虑升级套餐前，建议先检查ISP是否存在网络故障，并使用网线连接设备进行速度测试，以区分是宽带连接还是无线信号问题。你可以通过调整路由器摆放位置、切换更高效的5GHz频段或重启设备来排查并优化网络环境。若发现仅单一设备网速异常，应优先排查设备本身；若多台设备同时进行大量下载或高清串流，则可能需要更高带宽。建议用户在盲目升级前先进行系统性排查，确保每一环节都发挥出应有性能。只有在排除所有硬件和设置障碍后，若宽带速度依然无法满足家庭高负载的使用需求，才是考虑升级的最佳时机。

为什么我的 Internet 很慢？

Internet 很慢，不一定代表你的 Broadband Plan 不够快。

实际使用速度可能受到 Wi-Fi、Router 位置、连接设备数量、网络拥堵、设备能力、无线干扰，以及 ISP 网络问题等因素影响。

Unifi 的 EasyFix 允许用户自行检查 Internet Connection、Internet Speed 和 Wi-Fi 问题，然后才联系 TM。(Unifi EasyFix)

Maxis 的官方 Troubleshooting 指南则建议用户检查 Wi-Fi Connection、Internet Speed、Connected Devices、Restart Router 以及 Router Placement。(Maxis)

CelcomDigi 则特别提到 Wi-Fi Frequency、Router Placement、连接设备数量，以及使用 Ethernet 来测试真正的 Broadband Speed。(CelcomDigi)

TIME 也建议检查 Router Placement、Restart Router、Connected Devices、Wi-Fi Frequency 和 Device。(TIME)

所以，在决定升级 Broadband Plan 之前：

先找出到底是哪一个环节导致 Internet 变慢。

1. 先检查 ISP 有没有 Outage

在调整家里的设备之前，先检查 ISP 有没有发生 Network Outage。

Maxis 的官方指南建议用户在 Troubleshooting Internet 问题时检查 ISP 是否有 Outage。(Maxis)

Unifi 也会发布 Network Alerts，并列出受影响地区、原因以及恢复情况。(Unifi Alerts)

TIME 则提供 Service Status 页面，让用户使用 Service ID 检查服务状态。(TIME Service Status)

如果确认是 ISP 的 Outage，那么改变 Wi-Fi Settings 或升级 Broadband Plan 都无法解决根本问题。

2. 先确定是 Internet 慢还是 Wi-Fi 慢

可以简单理解成：

ISP Network → Fibre → ONT/Modem → Router → Wi-Fi → Device

其中任何一个环节出现问题，都可能让你感觉 Internet 很慢。

例如，如果进入家里的 Fibre Connection 正常，但 Bedroom 的 Wi-Fi Signal 很弱，那么从 300Mbps 升级到 1Gbps 可能没有帮助。

CelcomDigi 明确建议使用 LAN/Ethernet 将电脑直接连接 Router，再测试实际 Internet Speed。(CelcomDigi)

这样才能比较准确地判断问题究竟来自 Broadband Connection，还是家里的 Wi-Fi。

3. 正确测试 Broadband Speed

如果你想知道 Broadband Connection 是否真的慢，不要只依靠 Wi-Fi Speed Test。

CelcomDigi 建议使用 LAN/Ethernet 将 PC 或 Laptop 直接连接 Router，再使用可信的 Speed Test 网站进行测试。(CelcomDigi)

Maxis 也解释，Ookla Speed Test 测量的是设备的 Wi-Fi Speed，因此设备距离 Router 的距离、Concrete Walls 等 Physical Interference 都可能影响测试结果。(Maxis)

比较好的测试方式：

  1. 用 Ethernet Cable 连接电脑和 Router。
  2. 暂停大型 Download / Upload。
  3. 暂停 Cloud Backup 和 Game Updates。
  4. 关闭不必要的 Applications。
  5. 必要时重复测试几次。

4. 检查家里有多少设备正在使用 Internet

如果家里同时有很多设备进行大量 Internet Activities，整体体验可能会变慢。

TIME 建议检查是否有多个设备同时进行 High-Bandwidth Activities，例如高画质 Streaming、Large File Sync、Torrent Download 以及 Game / Application Updates。(TIME)

Maxis 也建议找出哪些设备正在消耗大量 Bandwidth，并在 Troubleshooting 时暂时限制或断开这些设备。(Maxis)

CelcomDigi 也指出，如果多个设备同时进行 Streaming、Gaming 或 Video Conferencing 等 Data-Intensive Activities，每台设备实际获得的速度可能会降低。(CelcomDigi)

所以不要一看到 Internet 慢就马上认为 Broadband Plan 不够。

5. 检查你使用的是 2.4GHz 还是 5GHz

CelcomDigi 表示，5GHz 通常速度更快，但覆盖距离较短；2.4GHz 速度通常较慢，但覆盖距离更广。 (CelcomDigi)

TIME 也给出了类似建议：靠近 Router 时可以使用 5GHz；距离较远时，2.4GHz 可能更适合。(TIME)

简单来说：

5GHz

  1. 通常速度更快
  2. 适合靠近 Router 的设备
  3. 覆盖范围较短

2.4GHz

  1. 通常速度较慢
  2. 覆盖范围较广
  3. 适合距离 Router 较远的设备

如果你发现：

Router 旁边很快 → 房间里面很慢

那么问题可能是 Wi-Fi Coverage，而不是 Broadband Plan。

6. 检查 Router 的位置

TIME 建议将 Router 放在开放、中央并且稍微高一点的位置，同时避免电子设备等可能造成干扰的来源。(TIME)

CelcomDigi 也建议将 Router 放在家里较中央的位置，并避免靠近可能干扰 Wi-Fi Signal 的电子设备。(CelcomDigi)

Maxis 则建议 Router 放在中央、远离墙壁和大型家具，并适当提高 Router 的位置。(Maxis)

尽量避免把 Router 放在：

  1. 柜子里面
  2. 大型家具后面
  3. 地板上
  4. 房屋角落
  5. 可能造成干扰的设备旁边

有时候，移动 Router 比升级 Broadband Plan 更有效。

7. Restart Router

Restart Router 是最基本的 Troubleshooting 方法之一。

TIME 建议关闭 Router、拔掉电源、等待 10 秒，然后重新开启。(TIME)

Maxis 则建议关闭 Router 并拔掉电源约 30 秒，再重新连接并等待 Router 完全启动。(Maxis)

CelcomDigi 的 Mesh Troubleshooting 流程也建议按照顺序关闭 Modem、Router 和 Mesh Unit，然后重新启动。(CelcomDigi)

但是不要随便 Factory Reset Router，因为这样可能会清除现有 Wi-Fi 和 Network Configuration。

8. 检查 Device

如果只有一台 Device 很慢，问题可能不是 Broadband Connection。

例如：

手机 A：慢

Laptop：正常

Smart TV：正常

这种情况下，应该先检查出现问题的 Device。

CelcomDigi 指出，一些较旧的 PC、Laptop、Phone 或 Tablet 可能只支持 2.4GHz Wi-Fi，因此设备本身可能成为速度限制。(CelcomDigi)

TIME 也指出 Physical Obstructions、Interference 和 Device Compatibility 都可能影响实际 Wi-Fi Performance。(TIME)

9. 检查 Ethernet Cable

如果你使用 Wired Connection 测试 Broadband Speed，Ethernet Cable 也可能成为 Bottleneck。

TIME 目前列出的典型 Cable 能力包括：

  1. Cat 5：最高 100Mbps
  2. Cat 5e：最高 1Gbps
  3. Cat 6：最高 10Gbps

实际表现仍然取决于 Network Equipment 和其他 Hardware。(TIME)

如果你刚刚从低速 Broadband Plan 升级到高速 Plan，但仍然使用旧 Network Equipment，就值得检查这一点。

10. 检查 Router 是否能够支持你的 Broadband Speed

如果你升级了 Broadband Plan，Router 本身也需要能够处理新的 Speed。

TIME 建议用户在升级 Broadband Speed 后检查 Router 是否兼容新的速度。(TIME)

所以 Troubleshooting 时不要只看 Broadband Plan。

也要看：

ISP → ONT → Router → Wi-Fi → Device

任何一个环节都有可能成为 Bottleneck。

什么时候才应该考虑 Upgrade Broadband Plan？

如果：

Wired Speed 正常，但 Wi-Fi 很慢

那么升级 Broadband Plan 未必有帮助。

如果：

多个 Device 都慢，而且 Wired Connection 长期明显低于预期

那么应该先联系 ISP，让他们检查 Connection。

如果：

Broadband Connection 正常，但家里长期有多人同时 Streaming、Gaming、Downloading 和 Working

那么你可能真的需要更多 Bandwidth。

CelcomDigi 表示，如果家庭经常有多个设备同时进行 Data-Intensive Activities，可以考虑更高速度的 Plan；Maxis 也说明更高 Bandwidth 可以为多个用户和设备提供更多容量。(CelcomDigi) (Maxis)

但是：

Upgrade 应该是根据实际需求做出的决定，而不是 Troubleshooting 的第一步。

NetBijak's Take

Internet 很慢，不代表你一定需要更快的 Broadband Plan。

这是消费者最应该知道的一点。

例如你订购的是 500Mbps，但手机通过 Wi-Fi 只有 80Mbps，这并不能直接证明 ISP 没有提供 500Mbps。

Wi-Fi Frequency、Router Placement、Device Capability、Interference 和家庭使用量，都可能影响实际速度。Unifi、Maxis、CelcomDigi 和 TIME 的官方 Troubleshooting 资料都强调了这些因素。

NetBijak 的建议很简单：

先 Troubleshoot，再 Upgrade。

如果 Wired Connection 正常，但 Wi-Fi 很差，就先检查 Wi-Fi Environment。

如果只有一台 Device 很慢，就检查 Device。

如果多台 Device 都慢，而且 Wired Connection 也长期异常，就联系 ISP。

如果 Broadband 本身正常，但整个家庭确实需要更多 Bandwidth，那么升级才可能是合理的选择。

NetBijak 的目的不是告诉你：

“买更快的 Broadband。”

而是帮助你了解：

“为什么你的 Internet 会慢。”

在真正花更多钱之前，先把问题找出来。
