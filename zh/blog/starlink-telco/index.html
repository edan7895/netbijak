Starlink × 马来西亚 Telco：卫星直连手机会改变马来西亚的手机网络覆盖吗？

马来西亚的手机网络未来可能出现一种新的 Coverage Layer：

来自太空，而不是来自传统 Telco Tower。

2026 年 7 月 30 日，马来西亚通讯部长 Fahmi Fadzil 表示，Starlink 计划在马来西亚进行 Direct-to-Device（D2D），也称 Direct-to-Cell（D2C）技术测试。

这项技术的目标，是让手机在没有传统电讯 Tower 的地区，通过卫星获得连接。

同时，MCMC 也被要求邀请本地 Telco 与 Starlink 探讨这项技术的合作机会。 (The Edge Malaysia

不过这里有一个非常重要的区别：

马来西亚目前并不是已经正式推出 Starlink 卫星直连手机服务。

目前仍然属于 Trial / Exploration Stage。

什么是 Starlink Direct-to-Cell？

很多人认识的 Starlink 是：

Starlink Dish → Satellite → Internet

这种模式通常需要安装 Starlink Antenna / Dish。

但是 Direct-to-Cell 是另外一种技术。

它更接近：

手机 → Starlink Satellite → Mobile Network

也就是说，卫星在某种程度上扮演一个：

“太空中的 Mobile Tower”

根据 SoyaCincau 的报道，Starlink Direct-to-Cell 的设计目标是让兼容的 4G LTE 手机直接连接卫星，而不需要另外购买 Satellite Phone 或 Starlink Dish。 (SoyaCincau

这也是为什么它对 Mobile Coverage 很有意义。

Direct-to-Cell 是不是代表以后不需要 Telco？

不一定。

反而目前马来西亚讨论的模式，很可能是：

Starlink + Telco

而不是：

Starlink vs Maxis / CelcomDigi / U Mobile

马来西亚政府已经要求 MCMC 邀请本地 Telco 与 Starlink 探讨合作。 (The Edge Malaysia

换句话说，Starlink Satellite 可以成为 Telco 的一个额外 Coverage Layer。

SoyaCincau 的解释是，Direct-to-Cell 可以把 Mobile Operator 的 Network 从地面延伸到太空，而卫星再连接回 Telco 的 Core Network。 (SoyaCincau

为什么 Telco 需要 Satellite Coverage？

马来西亚已经拥有大量 4G 和 5G Infrastructure。

那么为什么还需要 Satellite？

最大的原因其实是：

Geography + Economics

建设一个传统 Mobile Tower，需要：

  1. 土地
  2. Tower Construction
  3. 电力
  4. Backhaul
  5. Network Equipment
  6. Maintenance
  7. 长期运营成本

在 Kuala Lumpur 这种人口密集的地区，这种投资比较容易产生回报。

但如果一个地方：

人口很少
地理环境复杂
距离很远

Telco 为了几十、几百个用户建设一座 Tower，经济效益可能并不理想。

Fahmi 表示，一个新的 Telecommunications Tower 通常需要约 18–24 个月建设完成，而 D2D 在某些情况下可能提供更快、成本更低的覆盖方式。 (The Edge Malaysia

哪些地方可能最适合 Starlink Direct-to-Cell？

偏远地区

传统 Tower 难以建设或者成本太高的地区。

高速公路

部分 Highway 路段可能因为地理环境或建设成本而出现 Mobile Coverage Gap。

Sabah 和 Sarawak

面积大、地形复杂的地区可能尤其需要额外的 Coverage Solution。

Offshore 地区

传统 Mobile Tower 无法覆盖的海上区域。

紧急情况

如果 Flood、Landslide 或其他灾害破坏了地面 Telecommunications Infrastructure，Satellite Connectivity 可能提供额外的 Communication Option。

SoyaCincau 指出，这类技术主要适合作为 Rural Areas、Highways 和 Offshore Locations 的补充 Coverage Layer。 (SoyaCincau

使用 Direct-to-Cell 需要 Starlink Dish 吗？

这是传统 Starlink Broadband 与 Direct-to-Cell 最大的区别之一。

Traditional Starlink Broadband

通常需要：

Starlink Dish + Router + Power

Direct-to-Cell

目标则是：

Compatible Smartphone → Satellite

不需要专门的 Starlink Dish，也不需要 Satellite Phone。 (SoyaCincau)

对于消费者来说，这意味着它未来可能更像：

普通 Mobile Network

而不是：

另外安装一个 Satellite Internet System

普通手机都可以连接 Starlink 吗？

不能简单地说“所有手机都可以”。

目前技术的设计目标是支持兼容的 4G LTE 手机，但最终在马来西亚能使用哪些 Device，还要取决于：

  1. Telco
  2. Spectrum
  3. Device Compatibility
  4. Regulatory Approval
  5. 最终商业方案

SoyaCincau 报道称，这项技术可以使用兼容的现有 4G LTE 手机，而不需要专门的 Satellite Phone。 (SoyaCincau

所以消费者现在不应该理解成：

“只要我的手机是 4G，以后就一定可以连 Starlink。”

目前还没有这样的保证。

卫星直连手机会和 5G 一样快吗？

不要这样期待。

Direct-to-Cell 的主要价值并不是取代城市里的 4G / 5G。

它更重要的作用是：

在没有传统 Mobile Coverage 的地方提供基本 Connectivity。

SoyaCincau 指出，消费者不应该期待它拥有和传统 Mobile Network 相同的 Speed 和 Latency。早期用途更可能包括：

  1. Messaging
  2. Voice Calls
  3. Emergency Communications
  4. Limited Mobile Data

(SoyaCincau)

所以真正的比较不是：

5G vs Starlink

而更应该是：

No Signal vs Satellite-Assisted Connectivity

这两个概念差别很大。

手机需要看到天空吗？

这也是 Satellite Connectivity 的一个限制。

因为手机需要和几百公里高空的卫星建立连接，所以：

Clear View of the Sky

会比较重要。

SoyaCincau 指出，Direct-to-Cell 预计在拥有较好天空视野的情况下表现更好，因此更适合 Rural、Highway 和 Offshore 等户外环境。 (SoyaCincau

因此它并不是：

“无论在哪里、室内室外都一样强。”

Starlink 会取代 Mobile Tower 吗？

目前看来不太可能。

更现实的情况是：

城市

Fibre + 4G + 5G

↓

郊区

4G + 5G + Fibre

↓

偏远地区

4G/5G + Satellite Coverage

也就是说，Telco 继续在值得投资的地方建设 Tower，同时在一些建设成本过高的地区利用 Satellite Connectivity 补足 Coverage。

SoyaCincau 也明确把 Direct-to-Cell 描述为现有 4G / 5G Network 的补充，而不是取代。 (SoyaCincau

东南亚已经有 Telco 与 Starlink 合作

马来西亚并不是第一个探索这种模式的国家。

2026 年 2 月，菲律宾 Globe Telecom 宣布与 Starlink 达成 Direct-to-Cell 合作，成为东南亚首个推出 Starlink Direct-to-Cell 服务的 Telco。

Globe 表示，标准 LTE 手机可以直接通过 Satellite 使用 Data、Voice 和 Messaging，只要拥有比较好的天空视野。 (Utusan Malaysia / PR Newswire

这让我们可以看到：

Starlink + Telco

确实已经开始成为一种实际的 Telecommunications Model。

不过马来西亚最终如何实施，仍然需要看本地 Regulatory、Spectrum 和 Commercial Arrangement。

对马来西亚消费者有什么影响？

如果未来正式推出，Mobile Coverage 较弱的用户可能获得：

更好的 Coverage

尤其是 Rural / Remote Areas。

减少 Mobile Dead Zones

例如部分 Highway、山区和偏远地区。

Emergency Connectivity

当传统 Mobile Infrastructure 出问题时，Satellite 可以提供额外 Communication Channel。

减少某些地区建设 Tower 的必要性

Telco 可以在一些不经济的地区采用 Satellite Coverage。

不过消费者目前还有很多问题没有答案：

  1. 哪些 Telco 会参加？
  2. 哪些 Mobile Plans 支持？
  3. 会不会额外收费？
  4. 哪些手机支持？
  5. Speed 有多少？
  6. Voice / SMS 会不会支持？
  7. 室内能不能使用？
  8. 哪些地区会首先覆盖？

这些目前都不能提前下结论。

因为马来西亚目前还是：

Trial / Exploration Stage

NetBijak's Take

Starlink 这次提出的 Direct-to-Cell Trial，真正值得关注的地方，并不是：

“以后马来西亚人不用 Telco 了。”

而是：

Satellite Connectivity 可能成为马来西亚 Telecommunications Infrastructure 的另一层。

对于 Kuala Lumpur 等城市的消费者来说，如果本身已经拥有很好的 4G、5G 和 Fibre Coverage，Starlink Direct-to-Cell 可能没有太大的实际区别。

但是对于一个正在：

山里 / 偏远地区 / 海岛 / Highway

然后发现：

没有 Tower = 没有 Signal

的人来说，这项技术就可能非常有价值。

我们认为：

Starlink × Telco

其实比：

Starlink vs Telco

更值得关注。

未来可能是：

**Telco：**负责 Mobile Network、Customer、SIM 和 Commercial Service

**Starlink：**提供来自 Satellite 的额外 Coverage

双方未必需要互相取代。

不过，目前马来西亚只是计划进行 Trial，还不是 Nationwide Commercial Service。

所以消费者暂时没有必要因为这则新闻就马上更换 Mobile Plan，也没有必要为了 Direct-to-Cell 去购买 Starlink Hardware。

更值得关注的是接下来：

  1. 哪些 Telco 参加
  2. 哪些手机支持
  3. Coverage 到哪里
  4. Speed 有多少
  5. 是否支持 Voice / SMS
  6. 月费是多少
  7. Regulatory Approval 如何发展

如果最终能够成功实施，Satellite-to-Phone 很可能成为马来西亚解决部分 Mobile Coverage Gap 的另一种工具。
