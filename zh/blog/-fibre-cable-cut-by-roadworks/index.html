道路施工切断 Fibre Cable 后，整区宽带是怎样修复的？

✨ NetBijak AI 智能摘要

道路施工导致光纤电缆被切断，通常是因为受损线路属于核心的Feeder或Trunk架构，导致大片区域用户同时断网。修复过程并非简单的连接电缆，而是涉及故障定位、地下设施挖掘、复杂的熔接以及网络流量重定向等多个步骤。即使宽带服务通过备用路径提前恢复，物理线路的修复仍需较长时间以确保稳定性。不同ISP可能会共享同一段物理基础设施，因此即使品牌不同，也可能出现同时受灾的情况。建议用户在遇到区域性断网时，优先通过官方渠道查询服务状态，而非盲目重启路由器。

道路施工一不小心切断地下 Fibre Cable，附近几百甚至几千户的 Unifi、Maxis 或其他 Broadband 用户可能同时断网。

原因通常不是某一户的 Fibre Drop Cable 被切断，而是受损位置属于 Feeder、Trunk 或 Distribution Network，负责把网络带到多个下游地点。

为什么一条 Fibre Cable 可以影响整个区域？

FTTH 并不是每间屋子都单独拉一条光纤回到 ISP。

典型 PON 架构大致是：

ISP / OLT
│
Feeder / Main Fibre
│
Splitter / Distribution Point
│
Distribution Fibre
├── House A
├── House B
├── House C
├── House D
└── ...

Corning 的 FTTH 架构资料把网络分成 Feeder、Distribution 和 Drop 等部分。Feeder 位于较上游，连接 Central Office 与下游 Distribution Network。(Corning)

所以，如果 Roadworks 切断的是一段重要 Feeder Cable，影响范围自然远远超过被挖开的那一栋屋子。

Fibre 被切断后，会先做什么？

修复不是马上把两条断线接回去。

网络团队首先要确定：

哪里断？

哪些服务受到影响？

有没有其他路径可以暂时绕开？

通常流程是：

1. 发现故障

Network Monitoring 或大量用户投诉发现区域性断线。

2. 找到实际断点

Technician 使用 Fibre Testing Equipment 和网络记录定位故障位置。

3. 尝试 Rerouting

如果网络存在备用路径，流量可能先绕过损坏位置。

TM 过去曾处理过因为 MRT 和高速公路工程导致 Fibre Cable 被切断的事件。当时 TM 表示，实体 Fibre Repair 和 Replacement 还在进行时，技术团队已经通过 Rerouting Traffic 恢复受影响服务。(TM)

所以：

Internet 恢复 ≠ Fibre Cable 已经修好。

为什么道路施工会让修复变麻烦？

如果 Fibre Cable 埋在地下，Technician 不能直接站在路边把 Cable 接起来。

受损 Cable 可能位于：

  1. Underground Duct
  2. Manhole
  3. Handhole
  4. Cable Chamber
  5. Road Reserve

必须先取得安全施工空间，才能处理电缆。

JKR 的地下设施调查文件也明确涉及道路工程前的 Underground Utility Detection and Mapping，包括定位电力、电讯、水管和其他地下设施。(JKR)

因此，一次 Fibre Cut 很可能同时变成：

Telecom Repair + Excavation + Roadwork Coordination

而不只是普通的 Fibre Technician Callout。

被切断的 Fibre 要怎样修？

当 Cable 已经能够安全接触后，Technician 会判断：

是进行 Splicing，还是更换损坏的一段 Cable。

大型 FTTH Network 使用的是多芯 Fibre Cable，Feeder 与 Distribution Fibre 会通过专用的 Splice Closure 进行连接和保护。CommScope 的产品资料也明确显示，相关 Splice Closure 可用于 Feeder 和 Distribution Cable 的 Splicing。(CommScope)

所以维修不是简单地：

“两边的 Fibre 接起来就行。”

Technician 必须确认受影响的是哪几条 Fibre、正确准备 Fibre End、进行 Fusion Splicing，然后把接点放回适合的 Closure 中。

为什么 Main Trunk Cable 断了，可能修几天？

真正花时间的，往往不是 Fusion Splice 本身。

找到断点

道路工程可能覆盖、移动或破坏地下设施。Network Team 必须先确定准确的故障位置和受影响线路。

打开地下设施

如果断点在马路下面，可能需要 Excavation、Traffic Control 和现场安全安排。

处理高芯数 Fibre Cable

一条 Feeder Cable 可能承载多个下游 Network Services。

维修时必须逐一确认受影响 Fibre，不能随便接错。

恢复正常 Network Path

如果之前用了 Temporary Rerouting，实体线路修好后还需要把网络恢复到正常架构。

最后测试

完成 Splicing 或 Cable Replacement 后，需要进行 Fibre Testing，确认线路稳定后才能结束维修。

所以，主干 Fibre Cut 的维修时间不能拿普通家庭 Drop Cable 故障来比较。

为什么 Unifi 和 Maxis 可能同时断？

不同 Broadband Brand 不一定代表拥有完全独立的 Physical Route。

不同服务商可能经过共同的道路走廊、Duct、Infrastructure 或其他共用设施。

因此：

Unifi 是一个品牌、Maxis 是另一个品牌

并不自动代表：

两家公司在每个地区都有完全独立的地下 Fibre 路线。

如果两套服务在某个位置依赖同一个 Physical Infrastructure，就可能出现共同故障点。

ISP 可以绕过断掉的 Fibre 吗？

有时候可以。

如果网络有备用 Route 和足够 Capacity，ISP 可以把 Traffic Reroute 到另一条路径。

TM 就曾在 Fibre Cable 被道路工程切断的事故中，通过 Traffic Rerouting 先恢复服务，同时继续进行实体 Fibre Repair。(TM)

但能不能这样做，完全取决于当地网络架构。

不是每个住宅区都有足够的备用路径。

大范围断网时，用户应该先做什么？

如果同一地区突然很多邻居一起断网，不要第一时间不停 Reboot ONT。

先检查 ISP 是否公布了 Area Outage 或 Maintenance。

Unifi 提供 Service Alerts 与状态追踪功能，让用户查看网络和技术报告进度。(Unifi)

Maxis 也提供按地址查询的 Network Status Tool，可以查看 Planned Maintenance 和 Unplanned Disruption。(Maxis)

如果：

你的家断网 + 邻居也断网 + 同时发生

那就比单纯 Router Failure 更值得怀疑是区域性 Infrastructure Fault。

Unifi 的 24 小时修复承诺呢？

Unifi 目前公开提供 24-Hour Service Restoration，并说明在符合条件的情况下，如果正式报告建立后 24 小时内没有恢复服务，可获得 RM50 Bill Rebate。具体资格和例外情况以 Unifi 当前条款为准。(Unifi)

但不要把这个承诺理解成：

“任何道路工程切断 Fibre，都保证 24 小时内物理修好。”

Service Restoration 和 Physical Cable Repair 是两件不同的事情。

ISP 可以先通过 Rerouting 恢复服务，而受损的 Cable 可能仍在后续维修。

NetBijak’s Take

道路施工造成的 Fibre Cut 一旦发生在 Feeder 或 Main Trunk，影响范围可以远大于一户家庭。修复过程通常包括故障定位、取得地下 Cable、Splicing 或更换 Cable、网络切换和最终测试；如果有备用路径，ISP 甚至可以在实体 Fibre 修好之前先恢复部分或全部服务。
