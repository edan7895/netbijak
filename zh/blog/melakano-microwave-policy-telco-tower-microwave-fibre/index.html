Melaka「No Microwave Policy」是什么？为什么 Telco 正在把 Tower 从 Microwave 转向 Fibre？

✨ NetBijak AI 智能摘要

马六甲政府近期计划在未来五年内实施无微波政策，旨在逐步将电讯基站的传输方式从无线微波转向高容量的光纤技术。这项政策的核心是通过由Maxis与马六甲信息通讯控股公司合作的七年光纤化项目，将151座基站连接至光纤网络，以提升全州电讯基础设施的容量与稳定性。微波技术虽然在地形复杂或偏远地区仍具备部署快速的优势，但随着4G和5G数据流量激增，光纤回传技术已成为应对未来网络带宽需求的关键方案。此次升级主要是改善基站后端的传输链路，旨在解决潜在的网络瓶颈并提升整体数字高速公路的质量。对于消费者而言，光纤化能够为网络提供更高的容量储备，从而支持更稳定的上网体验。尽管这不代表用户的移动网络速度会立即获得统一提升，但该基础设施的强化是实现长期高速、高效连接的必要基础。

Melaka 为什么要逐步淘汰 Microwave？

马六甲正在推动更加以 Fibre 为基础的 Telecommunications Infrastructure。

2026 年 8 月 27 日，《The Star》报道，Melaka 计划在未来 五年内实施 No Microwave Policy，逐步淘汰 Microwave 作为电讯传输方式，并通过高容量 Optical Fibre 提升电讯网络的容量和稳定性。(The Star)

同一天，Bernama 报道了一个更具体的 Fibreisation Project：

Maxis 投资约 RM30 million，与 Melaka ICT Holdings（MICTH）合作，为 151 座 Telecommunications Towers 铺设约 200 公里 Fibre-Optic Network。

Bernama 报道这个项目预计需要 七年完成。(Bernama)

这里要特别注意：

五年 = Melaka 的 No Microwave Policy 方向
七年 = MICTH-Maxis 这个具体 Fibreisation Project 的预计时间

两者不是完全相同的时间表。


什么是 Telecom Microwave Transmission？

这里的 Microwave 和家里的：

Microwave Oven

完全没有关系。

Telecommunications 中的 Microwave Transmission，是利用无线电波，在不同 Telecommunications Sites 之间传输数据。

一个简单的 Mobile Network 可以理解为：

手机

↓

4G / 5G Tower

↓

Backhaul

↓

Telco Core Network

↓

Internet

其中：

Tower 到 Telco Network 的这一段，就是 Backhaul。

GSMA 将 Mobile Backhaul 定义为连接 Mobile Base Station 与运营商其他网络以及 Internet 的链路，并指出 Backhaul Capacity 会直接影响用户最终可以获得的网络表现。(GSMA)

Microwave 就是其中一种 Backhaul 技术。

也就是说，不一定需要在两个 Tower 之间铺设实体光纤，也可以用两个方向性的 Microwave Antennas 进行 Wireless Link。


为什么 Telco 以前会大量使用 Microwave？

因为 Microwave 有一个很明显的优势：

不需要像 Fibre 那样挖路、铺 Duct。

GSMA 指出，Microwave Backhaul 长期被广泛使用的重要原因之一，就是它可以比较快速地部署，而且不需要进行 Fibre 所需要的 Trenching 和 Ducting。(GSMA)

尤其是在：

  1. 地形复杂
  2. 偏远地区
  3. 道路不方便
  4. Fibre 铺设成本高
  5. 需要快速部署 Tower

的地方，Microwave 仍然很实用。

所以：

Microwave 并不是一个已经完全过时的技术。

MCMC 的 National 5G Task Force Report 也把 Microwave 列为解决真实 5G Deployment 问题的有效方案，并指出它具有部署速度快、灵活等优势。(MCMC National 5G Task Force Report)


那为什么 Melaka 现在想改成 Fibre？

最重要的原因之一是：

Capacity。

随着 4G 和 5G 使用量不断增加，越来越多 Data Traffic 需要经过 Mobile Network。

即使 Tower 本身有足够的 Radio Capacity，Tower 后面的 Backhaul 也必须有足够容量。

GSMA 明确指出，如果 Mobile Base Station 与用户之间的无线连接很快，但 Base Station 后面的 Backhaul 无法跟上 Traffic Demand，那么最终用户仍然无法充分获得网络能力。(GSMA)

Fibre 的优势就是：

能够提供非常高的传输容量。

GSMA 将 Fibre 描述为 Mobile Network 中重要的 Wired Backhaul Technology，并强调它本身拥有很大的 Bandwidth Capacity，同时还有进一步扩展的空间。(GSMA)


什么是 Fibre Backhaul？

Fibre Backhaul 简单来说，就是：

用 Optical Fibre 把 Mobile Tower 连接到 Telco 的更大网络。

原本可能是：

Tower → Microwave → Network

未来可以变成：

Tower → Fibre → Network

这里一个非常重要的概念是：

手机本身还是通过无线方式连接 4G / 5G Tower。

改变的是：

Tower 后面的 Network Connection。

所以 Melaka 并不是把：

Mobile Network 全部变成 Fibre。

而是增加：

Fibreisation of Telecommunications Towers / Backhaul

Bernama 报道，这次 MICTH-Maxis Project 会用约 200km Fibre Network 连接 151 座 Telecommunications Towers。(Bernama)


Fibre Backhaul 会让手机自动变快吗？

不一定。

这是消费者特别容易误解的地方。

改善 Backhaul 确实可以：

增加 Network Capacity

以及：

减少某些 Network Bottleneck

但手机最终得到多少速度，还会受到：

  1. Mobile Signal
  2. Spectrum
  3. Tower Capacity
  4. Network Congestion
  5. Device Capability
  6. User 数量
  7. Distance
  8. Routing
  9. Server

等因素影响。

所以不能简单说：

“Microwave 换 Fibre，所以所有人的 5G 都会变快。”

更准确的说法是：

Fibre Backhaul 为 Mobile Network 提供更高的后端容量，让网络更有能力应付不断增长的 Traffic。


这和 Home Broadband 有关系吗？

有关系，但不是直接升级你家的 Fibre。

这次 Melaka Project 主要针对的是：

Mobile Telecommunications Infrastructure

而不是：

Home Fibre Access Network

家庭 Broadband 大概是：

Home Router

↓

Fibre Access Network

↓

ISP Network

↓

Internet

手机网络则是：

Phone

↓

4G / 5G Tower

↓

Backhaul

↓

Telco Network

↓

Internet

两者虽然不同，但最终都依赖：

High-Capacity Network Infrastructure

所以这则新闻对于 Broadband 消费者仍然有意义。

它让我们看到：

Fibre 不只是用来接入家庭，也越来越多被用来连接 Telco 自己的网络基础设施。


为什么 Fibre Backhaul 对 5G 特别重要？

5G Network 可以产生非常大量的 Data Traffic。

MCMC 的 National 5G Task Force Report 就研究了 Fibre 和 Microwave 两种 Backhaul Solution，并显示不同 5G Deployment Scenario 对 Backhaul Capacity 的需求可以明显提高。(MCMC)

但 MCMC 同时也指出：

Fibre：

高容量

Microwave：

部署较快、更加灵活

所以不能简单解释为：

Microwave 不好，Fibre 好。

真正的问题是：

这个地点需要多少 Capacity？铺 Fibre 是否经济？Terrain 是否允许？部署速度是否重要？

Melaka 的政策反映的是：

在适合的地方，希望更多 Tower 使用高容量 Fibre。


Melaka 目前到底会做什么？

根据 Bernama：

**投资：**约 RM30 million

**Fibre：**约 200 km

**Telecommunications Towers：**151 座

**合作：**MICTH + Maxis

**预计时间：**7 年

(Bernama)

RTM 进一步报道，完成后，MICTH Tower 的 Fibre Connectivity 比例预计从约 40% 提高到 80%。RTM 同时报道，截至当时 Melaka 人口密集地区的 4G Coverage 已接近 100%，5G Coverage 则为 89.9%。(RTM)

MICTH 自己的网站则说明，它是 Melaka State Government-linked Company，同时也是 Licensed Network Facilities Provider，负责 Melaka 的 Digital Connectivity 和 Telecommunications Infrastructure。(MICTH)


什么是 Melaka 的 “Digital Highway”？

Melaka 政府把这项计划形容为：

Digital Highway

这里不是说真的会有一条：

“Internet Highway”

而是指：

利用高容量 Fibre Network 把不同 Telecommunications Infrastructure 连接起来。

Melaka Chief Minister 表示，这项合作将加强 Digital Connectivity Infrastructure，并支持 Technology-driven Economic Growth。(Bernama)

RTM 也报道，该计划的目标包括提升 Internet Speed、Capacity 和 Stability，并与 Smart Melaka Blueprint 2035 的方向一致。(RTM)


Fibre Backhaul 有什么优势？

更高 Capacity

Fibre 最大的优势之一就是能够传输非常大量的数据。

GSMA 指出 Fibre 本身拥有很高的 Bandwidth Capacity，并且可以通过 Wavelength Division Multiplexing 等技术进一步提高 Fibre 的整体 Capacity。(GSMA)


更适合未来升级

随着 Mobile Data Usage 增加，Tower 后面的 Network 也必须跟着升级。

Fibre 可以成为长期的 High-Capacity Infrastructure。

这并不代表每个用户今天就会突然获得更快速度，而是：

网络有更大的空间面对未来的 Data Demand。


更适合高流量 5G 地区

人口密集、商业活动多的区域可能产生大量 Mobile Traffic。

Fibre 可以提供足够的 Backhaul Capacity，减少 Tower 后方成为 Bottleneck 的可能性。

MCMC 的 5G Task Force Report 也针对不同 5G Scenario 研究了 Fibre 和 High-Capacity Microwave Backhaul。(MCMC)


在 Fibre 容易铺设的地方减少对 Wireless Backhaul 的依赖

Microwave 在 Fibre 很难铺设的地方仍然有价值。

但如果某个地点：

Fibre 可以经济地部署

那么 Fibre 通常能够提供更大的长期 Capacity。

这也是 Melaka 目前的方向。


这是不是代表 Microwave 全球都要消失？

不是。

这个区别非常重要。

Microwave 目前仍然是全球 Mobile Backhaul 的重要技术。

GSMA 的资料显示，Microwave 仍然广泛用于 Mobile Backhaul，其中一个原因就是：

部署快速，而且不需要挖 Fibre Trench。 (GSMA)

MCMC 的 National 5G Task Force Report 也同样认可 Microwave 在快速部署、Terrain 和成本方面的实际价值。(MCMC)

所以 Melaka 的政策应该理解成：

Melaka 自己的 Telecommunications Infrastructure Strategy

而不是：

“Microwave 已经被全球淘汰。”

某些偏远地区或 Fibre 建设成本很高的地点，Microwave 未来仍然可能是更实际的选择。


这会不会让 Melaka 的 Internet 变快？

有可能改善 Network Capacity 和整体 Network Performance，但不能保证每个人的 Speed 都会增加某一个固定 Mbps。

因为用户实际体验还受到：

  1. Network Congestion
  2. Radio Capacity
  3. Coverage
  4. Device
  5. Spectrum
  6. Backhaul
  7. Internet Routing
  8. Server

影响。

Melaka 政府确实将这项计划定位为提高 Speed、Capacity 和 Stability，但消费者不应该把它理解成：

“每个 Melaka 用户一定会增加 X Mbps。” (RTM)


为什么 Broadband 用户应该关心？

因为我们平时比较 Broadband 时，很容易只看到：

100Mbps vs 300Mbps vs 1Gbps

但一个 Internet Connection 背后还有一整套 Infrastructure：

Access Network

↓

Backhaul

↓

Core Network

↓

Internet

如果其中一个部分成为 Bottleneck，最终用户体验就可能受到影响。

Melaka 这次的 Fibreisation Project 就是一个很好的例子：

Telco 不只是升级消费者看到的“Plan”，同时也需要升级消费者看不到的网络基础设施。


NetBijak's Take

Melaka 将更多 Telecommunications Towers 从 Microwave Backhaul 转向 Fibre，是一个很值得关注的 Network Infrastructure Upgrade。

但是 NetBijak 不认为消费者应该把这则新闻理解成：

“Microwave 已经过时，Fibre 会自动让所有人的 Internet 变快。”

事情没有这么简单。

Microwave 仍然有自己的价值，特别是在 Fibre 很难铺设、建设成本很高，或者需要快速部署的地点。

Melaka 现在做的事情更具体：

在适合 Fibre 部署的地方，让更多 Telecommunications Towers 使用 High-Capacity Fibre，从而提升整个 Mobile Network 的 Backhaul Capacity。

这次 MICTH-Maxis Project 涉及约 151 座 Tower、200km Fibre 和 RM30 million Investment，而 Melaka 更大的 No Microwave Policy 则提出五年内逐步淘汰 Microwave Transmission 的方向。(Bernama) (The Star)

对于消费者来说，最值得记住的是：

Mobile Network 好不好，不只是看手机上的 4G 或 5G 信号，也要看 Tower 后面的 Network。

随着 4G 和 5G 的 Data Usage 持续增加，High-Capacity Backhaul 会变得越来越重要。

而这也说明了一件事：

Fibre 不只是连接家庭的技术，也正在成为连接整个 Connectivity Infrastructure 的基础。
