社区宽带与智慧乡区诊所：马来西亚政府无线网络计划

✨ NetBijak AI 智能摘要

马来西亚政府通过JENDELA和NADI双管齐下，旨在缩小城乡之间的数码鸿沟。JENDELA计划的核心在于升级全国网络基础设施，通过扩大光纤和无线网络覆盖来解决地区性断网或信号微弱的问题。相比之下，NADI作为社区数码中心，则为缺乏设备或稳定网络的居民提供上网空间、ICT课程及数码政府服务。对于乡区居民，当面对网络困境时，建议首先使用JENDELA Map查询覆盖情况并提交反馈或请求。若家庭网络尚未改善，附近的NADI中心不仅能提供基础网络接入，还延伸出e-Health等社区功能。这种基础设施建设与社区服务点互补的模式，是提升马来西亚乡区数码素养与连接能力的有效途径。

如果你住在 Kampung、偏远地区或网络覆盖较弱的地方，JENDELA 和 NADI 解决的是两个不同的问题：JENDELA 负责改善网络基础设施，而 NADI 提供一个让居民实际使用 Internet 和数码服务的社区据点。

什么是 JENDELA？

JENDELA（Jalinan Digital Negara） 是马来西亚推动全国数码连接与网络基础设施升级的计划。

它的重点不是推出一个新的 Broadband 配套，而是改善现有的网络基础设施，包括 Fibre、移动网络覆盖，以及适用于偏远地区的无线或卫星连接方案。

截至 JENDELA 第一阶段结束时，全国已有超过 774 万个地点可获得 Fibre Broadband，人口聚集区的 Internet / 4G 覆盖率也达到 96.92%。针对偏远地区，JENDELA 也部署了 839 个卫星宽带地点。（Source: MCMC — JENDELA Phase 1 Concluding Report）

JENDELA 如何帮助乡区居民？

对于住在城市的人来说，选择 Fibre 配套通常很简单：查看地址、检查 Port Availability，然后申请。

但在乡区，问题可能根本不是“应该选 100Mbps 还是 500Mbps”，而是：

  1. Kampung 有没有 Fibre？
  2. 手机 4G / 5G 覆盖够不够？
  3. 附近有没有 Broadband infrastructure？
  4. 如果地图显示有网络，为什么实际使用时却非常慢？
  5. 如果没有 Fibre，还有什么替代方案？

这也是 JENDELA Map 的用途。

JENDELA vs NADI：两者到底有什么不同？

项目JENDELA（Jalinan Digital Negara）NADI（Pusat Sebaran Maklumat Nasional）
核心角色全国数码基础设施计划社区数码服务中心
主要功能扩大 Fibre 覆盖、改善移动网络，并部署无线 / 卫星连接方案提供集体 Internet 使用、电脑、数码课程及社区服务
旧名称—Pusat Internet → PEDi → NADI
解决的问题“我的 Kampung 没有 Fibre 或手机信号很弱。”“家里没有电脑、Internet 或使用数码服务的条件。”
主要工具JENDELA MapNADI Location Directory

简单来说：

JENDELA 是解决“网络有没有到这里”。

NADI 是解决“居民在哪里可以使用 Internet 和数码服务”。

JENDELA Map 可以做什么？

JENDELA Map 不只是 Coverage Map。

用户可以根据州属、地区、Mukim 等位置查询网络情况，也可以：

  1. 查看网络覆盖
  2. 提交 Complaint
  3. 提交 Request
  4. 查询投诉 / 请求的处理状态
  5. 查找附近 NADI

官方的定义也有所区别：如果你遇到的是现有服务质量问题，可以提交 Complaint；如果某个地区没有 Fixed Broadband 服务，可以提出新的 Request。（Source: JENDELA — Frequently Asked Questions）

💡 Kampung 网络很差？NetBijak 4 步解决法

Step 1 — Check Coverage

先打开 JENDELA Map，检查你所在地区显示的网络覆盖情况。

Step 2 — Report the Problem

如果实际网络情况与地图显示不一致，可以提交 Complaint。

如果你的地区根本没有 Fixed Broadband，则使用相应的 Request 功能。

Step 3 — Find an Alternative

等待网络基础设施改善期间，可以通过 NADI Location Directory 找到附近的 NADI。

部分地区也有 NADI On Wheels，为网络资源不足的社区提供移动数码服务。

Step 4 — Consider Alternative Broadband

如果 Fibre 暂时无法安装，可以根据当地实际覆盖情况比较：

  1. 4G / 5G Router
  2. Fixed Wireless Access
  3. Satellite Broadband

不要单纯因为“速度最高”就选择方案，先确认该技术在你的地址是否真的可用。

PEDi 去哪里了？

如果你以前听过 Pusat Internet 或 PEDi（Pusat Ekonomi Digital），现在看到 NADI 不需要觉得奇怪。

PEDi 于 2024 年 3 月 1 日正式改名为 NADI（Pusat Sebaran Maklumat Nasional）。

NADI 的定位也不只是提供 Internet。它希望成为当地社区的数码服务据点，帮助居民使用 Internet、学习 ICT、接触政府数码服务，以及缩小城乡之间的数码落差。（Source: NADI — About NADI）

目前全国已有超过 1,000 个 NADI 中心。

NADI 可以做什么？

不同 NADI 的设备、服务和收费可能有所不同，因此不要假设每一个中心都提供完全相同的服务。

一般可以看到的服务包括：

  1. Internet 使用
  2. 电脑 / Laptop 使用
  3. 基础 ICT 课程
  4. 数码安全教育
  5. 学生线上学习
  6. 数码政府服务
  7. 社区活动
  8. 部分健康相关服务

例如部分 NADI 会提供免费 Wi-Fi 或电脑使用，但打印、扫描等服务可能另外收费。因此，前往之前最好先查看该 NADI 的具体页面。

NADI 的 Internet 是免费的吗？

不能一概而论。

部分 NADI 中心提供免费 Wi-Fi 或免费电脑使用，但具体规定取决于中心。

例如，有些中心规定会员可以免费使用电脑，而打印和扫描则收费；另一些中心可能设有使用时间限制。

所以，如果你的目的是寻找“免费 Internet”，应该先查看具体 NADI 中心的服务详情，而不是认为全国所有 NADI 都提供无限免费 Wi-Fi。

NADI 如何帮助学生？

对于没有 Fibre、电脑或稳定 Internet 的家庭，NADI 可以提供一个实际的替代使用地点。

学生可以利用中心的电脑和 Internet：

  1. 进行线上学习
  2. 搜索资料
  3. 使用教育平台
  4. 完成线上作业
  5. 学习基本 ICT 技能

这对于乡区家庭尤其有价值，因为问题有时并不是当地完全没有网络，而是家庭没有足够的设备或稳定连接。

NADI 与智慧乡区医疗有什么关系？

这里需要先澄清：

NADI 不是诊所，也不能取代医生或医院。

它的价值在于利用 Internet 和数码设备，把部分健康相关服务带到网络资源较有限的社区。

NADI 已经加入部分 e-Health / 数码健康相关服务，包括基本健康筛查，以及利用网络获取健康相关资讯和支援。

这意味着在一些乡区，居民不一定要因为一个简单的数码健康需求而面对完全没有网络资源的问题。

但涉及诊断、治疗或紧急医疗情况，仍然必须使用正规医疗服务。（Source: Jabatan Penerangan Malaysia — NADI e-Health development）

什么是 NADI On Wheels？

NADI On Wheels 是 NADI 针对偏远或服务覆盖不足社区推出的移动方案。

它不是固定在一个建筑物里的 NADI，而是把 Internet、数码活动、资讯传播和部分社区服务带到不同地区。

官方列出的服务包括：

  1. 免费 Internet 使用
  2. NADI 会员登记
  3. 数码活动
  4. 健康筛查
  5. 数码服务推广
  6. 社区资讯传播

对于距离固定 NADI 中心较远的 Kampung，这种移动模式尤其有实际意义。（Source: NADI — NADI On Wheels）

如果我的 Kampung 还是没有网络怎么办？

不要直接假设“乡区就是没有办法”。

先按照这个顺序检查：

Coverage → Complaint / Request → NADI → Alternative Broadband

如果 JENDELA Map 显示有覆盖，但你实际收到的服务明显不符，可以提交 Complaint。

如果当地没有 Fixed Broadband，则可以提出 Request。

与此同时，可以寻找附近 NADI，作为临时的 Internet 和数码服务地点。

如果 Fibre 确实无法到达，再考虑 4G / 5G Router、Fixed Wireless 或 Satellite Broadband。

JENDELA 与 NADI：记住这个区别

你可以把两者理解成：

JENDELA = Infrastructure

解决的是网络基础设施有没有覆盖到你的地区。

NADI = Community Access

解决的是居民有没有一个实际地点可以使用 Internet、电脑和数码服务。

所以，NADI 并不是 JENDELA 的替代品，两者实际上是互补的。

如何寻找附近的 NADI？

可以使用官方 NADI Location Directory，按照地点寻找附近的中心。

建议先查看具体中心的：

  1. 开放时间
  2. Internet 服务
  3. 电脑使用规定
  4. 会员要求
  5. 打印 / 扫描收费
  6. 其他社区服务

不同中心的服务可能有所不同。

NADI 可以取代家庭 Broadband 吗？

不能完全取代。

如果你需要长期在家工作、线上上课、Streaming、Gaming 或多人同时使用 Internet，家庭 Broadband 仍然更实际。

NADI 更适合：

  1. 临时 Internet 使用
  2. 没有电脑的家庭
  3. 学生线上学习
  4. 数码政府服务
  5. 基础 ICT 学习
  6. 部分社区数码健康服务

如果你只是偶尔需要电脑或 Internet，NADI 可以减少你必须马上申请家庭 Broadband 的压力。


NetBijak’s Take

JENDELA 和 NADI 最大的价值，不是让每一个乡区居民马上拥有高速 Fibre，而是分别解决“基础设施”和“使用条件”两个不同层面的问题。

如果你家里没有 Fibre，第一步不是盲目比较 Broadband 配套，而是先检查 JENDELA Coverage。

如果家里暂时没有足够的设备或网络条件，再找附近的 NADI。

对乡区用户来说，这个顺序比单纯追求一个“最高 Mbps”的 Broadband 配套更实际。
