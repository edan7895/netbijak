Unifi Internet 出问题怎么办？官方 Troubleshooting 步骤

✨ NetBijak AI 智能摘要

当Unifi网络出现故障或变慢时，建议先通过Unifi Alerts或EasyFix查询所在地区是否有官方维护或服务中断。接着，请检查路由器和ONT设备的指示灯状态，特别是留意LOS灯是否闪烁红色，以判断光纤连接是否存在物理损坏。若设备指示灯异常，尝试将设备断电并等待10秒后重新开启，通常能解决大部分临时性故障。如果重启后问题依旧，用户可使用EasyFix自助排查工具进行详细诊断。若上述步骤仍无法修复网络，系统将通过EasyFix自动建立报修工单或连接在线客服。请记住，在考虑升级宽带配套前，应优先按照此流程进行排查，以避免不必要的支出。

如果你的 Unifi Internet 很慢或者完全无法使用，先检查有没有 Outage，再检查设备和指示灯，然后重启设备，最后使用 EasyFix 自助排查。

1. 先检查有没有 Outage 或 Maintenance

在修改 Router Settings 之前，先确认所在地区有没有 Unifi Service Interruption 或 Maintenance。

Unifi 提供 Unifi Alerts，让用户查看服务中断以及受影响地区。(Unifi Alerts)

你也可以通过 EasyFix 的 Service Outage Checker 检查服务状态。(Unifi EasyFix – Service Outage)

如果确认是 Network Issue，单纯改变家里的 Wi-Fi Settings 通常无法解决根本问题。

2. 检查 Unifi 设备和指示灯

先检查：

  1. Power
  2. Fibre Cable
  3. Ethernet Cable
  4. ONT / BTU
  5. Router
  6. Indicator Lights

Unifi 官方资料建议用户检查设备指示灯，包括 PON Light，并确保 PON 灯稳定呈绿色。红色或闪烁的指示灯可能代表 Service Disruption。(Unifi System Upgrade FAQ)

特别注意：

LOS（Loss of Signal）

如果 LOS 灯闪红，代表 ONT 没有收到 Optical Power，或者 Fibre Connection 可能没有正确连接。(Unifi Equipment Guide)

PON

如果 PON 灯稳定绿色，代表 ONT 已经成功向 OLT 注册。(Unifi Equipment Guide)

不过，PON 绿色并不代表所有其他问题都已经排除，它只是说明 ONT 已经完成相关的 Optical Registration。

快速判断

PON — 稳定绿色

ONT 已成功向 Optical Network 注册。(Unifi Equipment Guide)

LOS — 闪红

ONT 没有收到 Optical Power，或者 Fibre Connection 可能没有正确连接。(Unifi Equipment Guide)

如果检查 Fibre Cable 并重启设备之后 LOS 仍然异常，就继续使用 EasyFix 或向 Unifi 报修。

3. 重启 Unifi 设备

Unifi 官方建议关闭相关设备，等待 10 秒，然后重新开启，并等待大约 2 分钟让服务恢复。(Unifi Installation Guide)

如果你的系统同时有 ONT/BTU 和 Router，就按照 Unifi 的说明重新启动相关设备。

这是最简单的 Troubleshooting 步骤之一，有时可以直接解决 Connection Problems。

4. 使用 Unifi EasyFix

如果 Restart 后问题仍然存在，可以使用 Unifi EasyFix。

EasyFix 可以帮助用户自助检查：

  1. Internet Connection
  2. Internet Speed
  3. Wi-Fi
  4. Telephony
  5. Unifi TV

Unifi 表示 EasyFix 可以通过 Unifi Portal、MyUnifi App 或 EasyFix Website 使用。(Unifi EasyFix FAQ)

还有一个很实用的功能：

即使家里的 Internet 完全断掉，也可以使用 EasyFix。

Unifi 表示用户可以通过手机 Browser 在没有 Active Internet Connection 的情况下访问 EasyFix。(Unifi EasyFix FAQ)

5. EasyFix 找到问题后怎么办？

如果 Self-Troubleshooting 还是无法解决问题，Unifi 官方表示 EasyFix 可以：

自动建立 Ticket / Report，或者提供 Live Chat。

(Unifi Promise)

这意味着用户不一定需要重新从头解释同一个问题。

不过要注意，Unifi 官方目前明确支持的是：

Automatic Ticket / Report Creation OR Live Chat

并没有表示每一次 Diagnostic Result 都会自动安排 Technician 上门。

6. 什么情况下应该联系 Unifi？

可以考虑联系 Unifi，如果：

  1. Restart 后仍然无法解决
  2. LOS 指示灯持续异常
  3. 多台设备都无法上网
  4. Internet 经常断线
  5. EasyFix 无法解决问题
  6. EasyFix 建立了 Report

Unifi 官方列出的 Support Channels 包括 Live Chat、Service Request Form 和 TM100 Hotline，其中 Live Chat 每天 24 小时提供服务。(Unifi Contact Us)

NetBijak's Take

Unifi 官方的 Troubleshooting 流程其实很直接：

检查 Outage → 检查设备和 LED → Restart → EasyFix → 联系 Support

其中 LOS 和 PON 指示灯可以作为第一层判断工具，特别是当你怀疑问题可能与 Fibre Connection 有关时。但指示灯只能提供线索，不能代替完整的技术诊断。(Unifi Equipment Guide)

最重要的是：

Internet 慢，不代表你一定需要升级 Broadband Plan。

先按照官方流程检查 Network、设备和 Fibre Connection，再根据实际情况决定下一步。

Troubleshoot first. Upgrade second.
