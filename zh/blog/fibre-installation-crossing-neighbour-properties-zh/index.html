Fibre 安装跨过邻居屋顶怎么办？马来西亚消费者如何解决纠纷

✨ NetBijak AI 智能摘要

在马来西亚安装宽带时，若遇到光纤线路需跨越邻居屋顶或私人范围的情况，切勿直接施工以免引发纠纷。目前并无明确禁止光纤跨越邻居屋顶的统一规定，因此建议将其作为安装服务争议处理，优先要求互联网服务供应商（ISP）进行技术路线评估，核实是否有其他可行路径。消费者应拍摄现场照片并详细记录沟通过程，以备后续升级投诉时作为证据。需要注意的是，更换路线或涉及埋设暗线等方案可能被界定为非标准安装，从而产生额外费用。若邻居拒绝接入，应明确要求ISP寻找替代方案或重新评估网络设计，而非强行施工。最终若ISP无法提供妥善解决方案，消费者可透过大马通讯及多媒体消费人论坛（CFM）寻求进一步的投诉协助。

如果 Fibre 安装人员告诉你，要把 Fibre cable 拉过邻居屋顶、树木甚至私人范围才能接入你家，不要急着和邻居吵，也不要马上接受这个路线。 先要求 ISP 记录施工情况，并检查是否可以通过其他 Pole、Distribution Point（DP）或 Fibre 路线接入。

这里最容易出现的误解是：很多人以为 “MCMC 规定 Fibre 不能跨邻居屋顶”。

目前并没有找到这样一条简单、统一的 MCMC 消费者规定。

实际问题通常涉及 ISP 的网络设计、现有 Pole/DP、installation standard、私人范围的 access，以及有没有其他技术上可行的路线。

为什么 Fibre 会需要经过邻居屋顶？

排屋（terrace house）的 Fibre 通常不是直接从你家门口开始铺。

网络可能从附近的 Fibre Distribution Point（DP）或 Pole 接出来，而 DP 的位置不一定刚好就在你家的正前方。

例如：

  1. 最近的 DP 在隔壁家的 Pole；
  2. 你的房子与 Pole 之间有排屋、沟渠或道路；
  3. 最短路线被大树挡住；
  4. 现有 Fibre infrastructure 的位置有限；
  5. Installer 根据现有 network route 选择 aerial cable。

于是就可能出现：

Pole → 邻居房屋上方 → 你的房子

这种情况。

但要注意：

Installer 能够拉过去，不代表这就是唯一可行路线。

所以遇到争议时，第一步不是和邻居争论，而是要求 ISP 做 technical route assessment。

MCMC 有没有规定 Fibre 不能跨邻居私人范围？

这点必须讲清楚。

目前没有找到一条可以简单理解为：

“Fibre cable 绝对不能跨过邻居私人土地或屋顶。”

的 MCMC 消费者规定。

因此，NetBijak 不建议消费者直接拿“MCMC 禁止跨界拉 Fibre”去和 ISP 或 Installer 理论。

比较准确的做法，是把问题当成 Fibre installation / service delivery dispute 处理。

CFM 的消费者投诉渠道涵盖包括 Service Delivery、Terms & Conditions Disputes、Unfair Practice 等通讯服务问题。

(Source: CFM — Complaint Channels)

CFM — Complaint Channels (cfm.my)

所以真正应该问 ISP 的问题是：

“这个路线是不是唯一技术上可行的路线？有没有检查过其他 Pole、DP 或 Fibre route？”

如果 Fibre Cable 要跨过邻居屋顶怎么办？

这是排屋最容易发生纠纷的情况之一。

先不要让 Installer 直接开工。

确认以下几个问题：

  1. Fibre 从哪一个 Pole / DP 出来？
  2. Cable 会不会直接经过邻居屋顶？
  3. Cable 会不会固定在邻居房屋上？
  4. 以后维修是否需要进入邻居家？
  5. 有没有其他 Pole 或 DP？
  6. 有没有其他 aerial route？
  7. Underground Fibre 是否可行？
  8. ISP 有没有做过 alternative route assessment？

建议先拍照。

最好把以下位置拍清楚：

Pole → DP → 邻居屋顶 → 树木 → 你的房子 → Property Boundary

然后把照片交给 ISP。

你可以这样要求：

“The proposed Fibre route crosses a neighbouring private property. Please arrange a technical route assessment and advise whether an alternative pole, Distribution Point (DP) or Fibre route is available.”

这比单纯告诉客服：

“我不要 Fibre 经过邻居家。”

有效得多。

如果是邻居的树挡住 Fibre 路线呢？

树的问题比屋顶更加复杂，因为树会继续生长。

现在没有碰到 Cable，不代表几年后不会碰到。

长期可能出现：

  1. 树枝压到 Fibre cable；
  2. 大风导致树枝碰撞 Cable；
  3. 修树时误伤 Fibre；
  4. Cable 与树枝长期摩擦；
  5. 维修人员无法安全接近 Cable。

如果 Installer 要把 Fibre 拉过邻居的大树，先问清楚：

  1. Cable 会不会接触树枝？
  2. 是否有足够 clearance？
  3. 有没有其他路线？
  4. 如果以后树枝损坏 Cable，由谁负责？
  5. 是否需要修剪树木？

不要自己去砍邻居的树。

如果施工真的需要修改邻居范围内的树木，应先由 ISP 和相关屋主处理。

可以要求 ISP 换 Pole 吗？

可以要求，但不代表 ISP 一定必须换。

这是两个不同的问题。

你可以要求 ISP：

  1. 检查附近其他 Pole；
  2. 检查其他 DP；
  3. 重新设计 aerial route；
  4. 检查 surface cabling；
  5. 检查 underground cabling；
  6. 评估 Pole relocation。

但 ISP 是否真的可以更换 Pole，要看 network design 和技术可行性。

因此不要只说：

“Move the pole.”

更好的说法是：

“The current pole position requires the proposed Fibre cable to cross a neighbouring private property. Please assess whether another pole, DP or network route can be used, and advise whether pole relocation is technically feasible.”

这样 ISP 才会把问题交给真正负责 network planning 的团队。

Unifi 的 Standard Installation 怎么算？

Unifi 官方目前对不同 Fibre installation 方法有明确区分。

其中：

Pole → Entry Wall 的直接 Cable

属于 Standard Installation，由 TM 提供。

而：

Pole → Entry Wall，需要经过 underground + surface cabling

则属于 Non-Standard Installation，官方页面目前列出的 Cabling Charge 是 RM212。

(Source: Unifi — Home Broadband Installation Journey)

Unifi — Home Broadband Installation Journey (unifi.com.my)

这说明一个很重要的问题：

有 Alternative Route，不代表 Alternative Route 一定免费。

所以如果客服告诉你：

“可以换路线，但要另外收费。”

不要马上答应。

先问清楚：

  1. 什么 Installation Method？
  2. 为什么属于 Non-Standard？
  3. 需要什么工程？
  4. Cable 多长？
  5. 是否需要 underground work？
  6. 是否需要 Surface Cabling？
  7. 有没有其他额外费用？

Maxis Fibre 又是怎样？

Maxis 同样区分 Standard Installation 和 Non-Standard Installation。

Maxis 官方资料说明，其 Standard Installation 一般涵盖从最近的 Fibre Distribution Panel 到 Modem 的首 100 metres，并包括例如沿墙使用 clips 的标准布线方式。

如果需要超过标准范围，或者使用 underground ducts、concealed wiring、over-ceiling cabling 等方式，则可能产生额外费用。

(Source: Maxis — Fibre Installation FAQs)

Maxis — Fibre Installation FAQs (maxis.com.my)

所以无论是 Unifi、Maxis 还是其他 Fibre ISP，遇到特殊路线时都应该先问：

这是 Standard Installation，还是 Non-Standard Installation？

如果邻居不同意怎么办？

如果邻居明确表示不允许 Fibre Cable 经过他的屋顶或私人范围，不要强行施工。

直接告诉 ISP：

“The neighbouring property owner does not agree to the proposed Fibre route. Please assess whether an alternative pole, DP or Fibre route is available.”

然后要求客服把这个情况记录在 Installation Ticket。

这样以后如果问题升级，你可以证明：

不是你拒绝 Fibre installation，而是 proposed route 涉及邻居私人范围，因此要求 ISP 提供其他方案。

如果 ISP 回复：

“没有其他路线。”

继续问：

  1. 有没有检查其他 Pole？
  2. 有没有检查其他 DP？
  3. 有没有检查其他 aerial route？
  4. Underground route 是否可行？
  5. Surface cabling 是否可行？
  6. Alternative route 是否需要额外收费？

如果要申请更换 Fibre Pole 呢？

可以申请，但不要把它写成：

“我要求你们一定要搬 Pole。”

比较合理的写法是：

“Please assess whether pole relocation is technically feasible because the current pole position requires the Fibre cable to cross a neighbouring private property.”

重点是 request an assessment。

因为 Pole 属于 network infrastructure，ISP 需要从网络规划、现有基础设施以及施工可行性判断是否能够更换。

如果 Installer 说：“只有这一条路线。”

不要马上认为事情就结束了。

Installer 通常是按照现场已有 infrastructure 和 installation instruction 工作。

如果涉及：

  1. 邻居不同意；
  2. 屋顶；
  3. 树木；
  4. 私人范围；
  5. Pole；
  6. Alternative Route；

就应该要求 ISP 的 technical/network team 重新评估。

可以直接这样写：

“Please escalate this installation for a technical route assessment. The proposed cable route crosses a neighbouring private property, and the property owner does not agree to the proposed route. Please confirm whether another pole, DP or Fibre route has been assessed.”

这比一直和 Installer 争论有效得多。

Alternative Route 要收费怎么办？

有可能收费。

Unifi 官方目前明确把某些 underground + surface cabling 列为 Non-Standard Installation，并列出 RM212 Cabling Charge。

(Source: Unifi — Home Broadband Installation Journey)

Unifi — Installation Guide (unifi.com.my)

Maxis 也说明某些 Non-Standard Installation 会产生额外费用。

(Source: Maxis — Fibre Installation FAQs)

Maxis — Installation FAQ (maxis.com.my)

所以消费者在接受 Alternative Route 前，最好要求 ISP 确认：

  1. Installation Method；
  2. Cable Length；
  3. Underground / Surface Work；
  4. 是否需要新 Pole；
  5. Additional Charges；
  6. 谁负责相关工程。

先确认费用，再让他们施工。

应该保存什么证据？

如果你认为 Fibre 路线有问题，不要只靠电话投诉。

保存：

Pole 照片

拍下 Pole 和周围房屋。

DP 照片

如果 DP 在安全、允许拍摄的位置。

Cable Route 照片

清楚显示 Installer 打算怎么拉线。

Roof / Tree 照片

如果它们是争议的重点，就拍下来。

Property Boundary

让 ISP 看得出 Cable 为什么需要经过邻居范围。

所有沟通记录

包括：

  1. WhatsApp；
  2. SMS；
  3. Email；
  4. Installation Ticket；
  5. Order Number；
  6. Installer 的回复；
  7. Customer Service 的回复；
  8. Quotation；
  9. 照片。

这些资料以后投诉时非常有用。

ISP 不解决，可以投诉 MCMC 吗？

可以。

不过建议先给 ISP 一个合理的机会处理。

如果一直没有解决，可以通过 MCMC/CFM 的消费者投诉机制进行升级。

CFM 的投诉渠道涵盖包括 Service Delivery 和 Terms & Conditions Disputes 在内的通讯服务问题。

(Source: CFM — Complaint Channels)

CFM — Complaint Channels (cfm.my)

消费者可以通过 MCMC Consumer Redress Portal 提交投诉，也可以联系：

MCMC Consumer Care Centre：1800-188-030

(Source: CFM — New Complaint)

CFM — New Complaint / MCMC Consumer Redress Portal (cfm.my)

投诉时不要只写：

“ISP 不给我装 Fibre。”

应该把完整过程写出来。

例如：

“I applied for Fibre installation. The installer proposed an aerial cable route crossing a neighbouring private property. The neighbouring owner does not agree to the proposed route. I requested an alternative pole, DP or technical route assessment, but the issue remains unresolved.”

然后附上：

照片 + Ticket Number + WhatsApp + Email + ISP 回复。

这样投诉会清楚很多。

MCMC 会不会直接叫 ISP 搬 Pole？

不要这样预期。

投诉机制可以让消费者的服务问题进入正式处理流程，但并不代表 MCMC 会自动要求 ISP 在你指定的位置安装新 Pole。

实际解决方案仍然取决于：

  1. Network Infrastructure；
  2. DP 位置；
  3. Technical Feasibility；
  4. Installation Standard；
  5. Property Access；
  6. Construction Work；
  7. 相关审批。

CFM 的职责包括通过消费者投诉机制协助处理通讯服务相关投诉，并根据适用的消费者规范进行调解和解决。

(Source: CFM — About Us)

CFM — About Us (cfm.my)

所以投诉的目标应该是：

要求 ISP 对你的情况给出正式、合理的技术处理方案。

而不是直接要求监管机构帮你重新设计 Fibre network。

这些事情不要自己做

不要剪 Fibre Cable

即使你认为 Cable 经过你的范围，也不要自己剪。

直接向 ISP 投诉。

不要自己搬 Pole

Pole 属于 network infrastructure，不是屋主可以自行移动的东西。

不要砍邻居的树

即使树挡住 Fibre route，也不能因此自行处理邻居的财产。

不要先让他们安装，之后才投诉

如果你已经知道 Cable Route 有争议，最好在施工前解决。

不要只和 Installer 争论

涉及邻居、Pole、DP 或 Alternative Route 时，要求 ISP 的 technical/network team 介入。

最简单的处理流程

如果你的 Fibre installation 因邻居物业而出现问题，可以按照这个顺序：

1. 拍下 Proposed Route

Pole、DP、Roof、Tree、Property Boundary 全部记录。

2. 要求 Installer 记录问题

确保 Installation Ticket 有记录。

3. 联系 ISP

说明 proposed route 涉及邻居私人范围。

4. 要求 Technical Route Assessment

明确询问其他 Pole、DP 或 Fibre Route。

5. 询问 Alternative Installation

例如 Surface 或 Underground Cabling。

6. 询问费用

特别是 Non-Standard Installation。

7. 保存所有记录

WhatsApp、Email、Ticket、照片、Quotation 都保留。

8. ISP 仍然无法解决，再升级 MCMC/CFM

提交完整的时间线和证据。

可以直接发给 ISP 的投诉模板

如果你正在申请 Unifi、Maxis 或其他 Fibre，可以直接发送：

“The proposed Fibre installation route crosses a neighbouring private property / roof / tree, and the property owner does not agree to the proposed route. Please arrange a technical route assessment and advise whether an alternative pole, Distribution Point (DP), aerial route or other Fibre route is available. If an alternative installation is considered non-standard, please provide the installation method and applicable charges before proceeding.”

重点不是叫客服“换 Cable”。

而是要求：

Technical Route Assessment。

NetBijak's Take

Fibre 安装遇到邻居问题，首先应该把它当成一个 network route + installation issue，而不是邻居之间的私人战争。

目前没有足够依据告诉消费者：

“MCMC 规定 Fibre Cable 绝对不能跨邻居屋顶。”

这种说法太绝对。

更实际的处理方式是：

拍照记录 → 要求 ISP 重新检查路线 → 询问其他 Pole / DP → 要求 Alternative Route → 确认是否属于 Non-Standard Installation → 确认费用 → 无法解决再向 MCMC/CFM 投诉。

如果 proposed route 涉及邻居屋顶、树木或私人范围，不要自己砍树、搬 Pole 或剪 Fibre Cable。

消费者最有力的说法不是：

“MCMC 说你不能这样拉。”

而是：

“The proposed route crosses a neighbouring private property. Please conduct a technical route assessment and confirm whether an alternative pole, DP or Fibre route is available.”

这句话把问题交回 ISP 的 network team，让他们回答一个真正需要回答的问题：

有没有其他技术上可行的路线？
