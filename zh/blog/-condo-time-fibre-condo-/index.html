为什么朋友的 Condo 有 TIME Fibre，你的 Condo 却没有？

为什么朋友的 Condo 有 TIME Fibre，我的却没有？

这种情况在马来西亚其实很常见。

你朋友住在附近的 Condo，可能只是几百米、甚至同一个地区。

他用的是 TIME Fibre，网速快，月费看起来也不错。

然后你去 TIME 网站输入自己的地址，却发现：

TIME Fibre 暂时没有覆盖你的 Condo。

很多人第一反应都会是：

「奇怪，我朋友明明就在附近，为什么他的有，我的没有？」

答案其实很简单：

马来西亚的 Fibre Broadband 覆盖，并不是单纯看“这个地区有没有 TIME”，而是可以细到具体的 building。

TIME 官方 FAQ 也明确说明，住宅配套的 availability 会根据地址而定，而且 plan availability varies by building。TIME 的 coverage checker 也要求用户输入 building 或 street name 来检查。(Time Internet)

1. Fibre Broadband 跟手机网络不一样

很多人会把 Fibre Broadband 和手机网络的 coverage 混在一起。

例如你看到朋友在同一个地区可以用 TIME，就会觉得：

「TIME 都已经来到这里了，应该整区都有吧？」

其实不是。

手机网络主要通过基站覆盖一个范围。

但 Fibre Broadband 不一样。

光纤需要实际的网络基础设施接到建筑物。

TIME 本身拥有和运营自己的 fibre network，而不是单纯使用 TM 的全国网络。TIME 过去也解释过，因为自己建设和运营网络，可以更直接控制服务质量。(Time Internet)

所以 TIME 的 fibre 到了你朋友的 Condo，不代表已经接到你的 Condo。

2. 你朋友的 Condo 可能已经是 TIME-ready Building

这是最常见的原因。

假设有两栋 Condo：

Condo A

TIME 已经把 fibre infrastructure 接进去了。

所以：

  1. 大厦已经连接 TIME network
  2. 可以把 fibre 接到住户
  3. 屋主可以申请 TIME
  4. 安装人员可以进行 installation

Condo B

虽然 TIME 的网络可能就在附近，

但：

  1. 大厦本身还没有接入
  2. 还没有完成相关 infrastructure
  3. 或者目前还没有开放给住户申请

那么住在 Condo B 的你，就可能无法申请 TIME。

两栋 Condo 可能只相隔 500 米，但 broadband availability 完全可以不一样。

TIME 官方 FAQ 直接说明，plan availability 会根据 building 而有所不同。(Time Internet)

3. Condo 的管理和内部基础设施也很重要

住 Condo 跟住 landed house 是不一样的。

Fibre provider 如果要进入一栋已经建好的 Condo，可能需要处理：

  1. building entrance
  2. cable route
  3. riser
  4. telecom room
  5. common area
  6. unit connection

所以不是简单地把一条 fibre cable 拉到你家门口就完成。

TIME 的官方安装资料也区分了 pre-laid unit 和 non-prelaid unit。

如果你的单位已经有 fibre socket，安装会比较简单；如果没有，installer 可能需要从单位外面把 fibre 拉进屋内。(Time Internet)

所以不同 Condo 的 infrastructure 条件，也会影响安装难度。

4. TIME 不可能一次过把所有 Condo 都接进去

建设 Fibre network 是需要成本的。

Provider 通常需要考虑：

  1. 一栋楼有多少单位
  2. 潜在用户数量
  3. 人口密度
  4. 现有基础设施
  5. 建设成本
  6. 用户需求
  7. 网络扩展计划

例如：

一栋有 500 个单位的 Condo，如果可以一次覆盖很多潜在用户，商业上可能比一栋只有几十户的住宅区更容易优先部署。

TIME 过去也说明过，其 fibre deployment 曾优先考虑人口密集的城市地区，因为高密度住宅的 fibre rollout 更具经济效益。TIME 也特别提到，连接拥有数百单位的 high-rise building，在经济上可能比连接分散的住宅更有效率。(Time Internet)

5. 同一个地区，不代表 broadband 选择完全一样

例如你可能看到：

CondoTIME Fibre
Condo A 有
Condo B 没有
Condo C 有
Condo D 没有

四栋楼可能就在同一条路。

所以真正应该问的不是：

「TIME 有没有覆盖我住的地区？」

而是：

「TIME Fibre 有没有覆盖我住的这栋 building？」

这也是为什么 TIME 的官方 coverage checker 会让用户输入 building 或 street name，而不是只选择 Kuala Lumpur、Selangor 这种大范围地区。(Time Internet)

6. 你的 Condo 有 Fibre，也不代表一定有 TIME

这个误会也非常常见。

你可能会说：

「我的 Condo 明明已经有 fibre 了，为什么 TIME 不能装？」

因为：

有 Fibre ≠ 有 TIME Fibre。

一栋 Condo 可以已经有 Unifi 或其他 provider 的 fibre infrastructure，但不代表 TIME 的 network 也已经进入这栋楼。

TIME 自己拥有独立的 fibre network，而不同 provider 的网络部署方式也不完全一样。(Time Internet)

所以：

Condo 有 Unifi

≠ Condo 一定有 TIME

7. 今天没有，不代表以后永远没有

如果 TIME 今天检查你的地址显示：

Not available

也不代表你的 Condo 永远都不会有 TIME。

TIME 官方 coverage 页面允许没有覆盖的用户把地址加入 Wish List，同时 TIME 也表示会继续扩大 fibre coverage。(Time Internet)

特别是一些新建 Condo、新住宅区，随着入住率提高以及网络扩展，未来可能会有新的 provider 进入。

不过要注意：

除非 TIME 官方确认，否则不能保证什么时候会覆盖你的 Condo。

8. 我的 Condo 没有 TIME，可以怎么办？

你可以按照这几个步骤：

第一步：检查你的完整地址

直接使用 TIME 官方 coverage checker，输入你的 building 或 street name。(Time Internet)

第二步：比较其他 Fibre provider

如果 TIME 没有，不代表你没有其他选择。

可以比较：

  1. Unifi
  2. Maxis
  3. CelcomDigi
  4. 其他在你地址可以申请的 Fibre provider

第三步：问 Condo Management

如果很多住户都有兴趣，可以询问：

  1. JMB
  2. MC
  3. Building Management

看看 TIME 之前有没有联系过管理层，或者未来有没有 fibre infrastructure 的计划。

第四步：加入 TIME Wish List

如果目前没有覆盖，可以把地址提交到 TIME 的 Wish List。(Time Internet)

为什么朋友有 TIME，你却没有？最简单的答案

因为 Fibre Broadband 的覆盖可以细到 building level。

你朋友的 Condo 可能已经连接 TIME 的 fibre network。

而你的 Condo：

  1. 可能还没有接入
  2. 可能还没有完成 infrastructure
  3. 可能暂时不在 TIME 的 rollout priority
  4. 或者目前还没有开放服务

所以即使两个 Condo 只相隔几百米，结果也可能完全不同。

住得近，不代表可以用同一个 Fibre provider。

NetBijak 小贴士

不要因为：

「我朋友用 TIME。」

就直接认定你也可以申请 TIME。

在马来西亚选择 Fibre Broadband，最重要的是：

  1. 先检查自己的 exact address。
  2. 看你的 building 有哪些 provider。
  3. 比较月费。
  4. 比较 download 和 upload speed。
  5. 看合约期限。
  6. 根据家里实际人数和使用习惯选择。
  7. 不要只看朋友家的配套。

最好的 Broadband Plan，不一定是最快的，而是你自己的地址真正可以申请、价格又适合你的配套。
