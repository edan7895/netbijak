TM HSBA vs TIME vs Allo：了解共享与自建 Fibre 网络的区别

✨ NetBijak AI 智能摘要

在马来西亚选择宽带时，决定网速和稳定性的关键不仅在于ISP品牌，更在于你家接入的是哪种底层光纤网络。TM HSBA、TIME与Allo代表了三种不同的运营模式，分别涵盖了全覆盖批发服务、全链路自建网络及开放式基础设施模式。网络所有权决定了运营商在底层链路上的控制力与扩容效率，但并不意味着自建网络就一定完全不拥堵。实际的上网体验受访问网络容量、ISP核心网、路由优化及国际带宽等多种因素共同影响，而非单一因素决定。因此，消费者在对比套餐时，应跳出单纯的带宽数字，重点考量该地址底层的网络归属以及ISP在高峰期的带宽规划与路由表现。最理想的评估方式是综合考察你的地理位置、具体光纤接入方以及该ISP提供的上游网络质量。

同样是 500Mbps Fibre，实际用起来却可能不一样。原因不一定是 ISP 的套餐，而是你家背后的 Fibre 网络是谁在运营。

在马来西亚，常见的网络模式包括 TM HSBA Wholesale、TIME 自建 Fibre，以及 Allo 的开放式 Fibre 网络。

真正值得比较的，不只是“谁的 Mbps 比较高”，而是：

谁负责你家到网络节点的 Fibre？ISP 又如何把这条连接接入自己的 Core Network 和 Internet？

TM HSBA 是什么？

HSBA（High-Speed Broadband Access） 是 TM 提供的 Wholesale 网络接入服务。

简单来说，其他 ISP 不需要自己在每个住宅区重新铺一套 Fibre，而可以通过 TM 的 HSBB 网络提供 Broadband 服务。

Maxis 官方的 Fibre 网络资料就直接列出 TM-HSBA、Allo 和 TIME 等不同的网络提供商，并说明 TM-HSBA 是 Telekom Malaysia 提供的 High-Speed Broadband Access 网络。

Source: Maxis — List of Providers

Maxis 官方网络提供商资料

这也解释了为什么：

你订的是 Maxis / CelcomDigi 等品牌，不代表你家门口的 Fibre 一定是这个品牌自己铺的。

同一个 ISP，在不同地址甚至可能使用不同的底层网络。

TM HSBA = 高峰期一定塞车？

不是。

这是这篇文章最需要厘清的地方。

很多人会把：

TM Wholesale → 多个 ISP 共用 → 晚上一定拥堵

直接画上等号。

但网络实际上没有这么简单。

你的 Fibre 连接可以大致理解为：

Home → Access Network → Aggregation → ISP Core → Peering / Internet Exchange → International Network → Website / Game Server / Streaming Service

任何一个环节容量不足，都可能影响你的体验。

例如：

  1. Access Network 容量不足
  2. ISP Aggregation 出现拥堵
  3. ISP Core Network 容量不足
  4. International Transit 不够
  5. Peering 路由不理想
  6. 某个 CDN 或游戏服务器本身出现问题

因此，即使你使用的是 TM HSBA，也不能直接说晚上一定慢。

反过来也一样：

自建 Fibre 也不代表绝对不会拥堵。

TIME：自己拥有 Fibre 网络

TIME 与 TM HSBA 最大的区别之一，是 TIME 在其覆盖范围内运营自己的 Fibre 基础设施。

TIME 官方明确表示，其 Home Fibre 使用 100% 自有 Fibre Network，并强调拥有完整网络控制权。

Source: TIME — Our Fibre Network

TIME 官方 Fibre Network 页面

TIME 的企业资料也指出，其完整 Fibre 网络以 Cross Peninsular Cable System（CPCS） 为核心，构成其全国 Fibre 网络的一部分。

Source: TIME — Who We Are

TIME 官方企业资料

这带来的主要优势不是一句“速度比较快”这么简单。

而是：

TIME 对更多网络环节拥有直接控制权。

包括：

  1. Access Network
  2. Network Capacity
  3. Network Upgrade
  4. Fault Management
  5. Network Engineering
  6. 部分流量优化

TIME 也明确宣传其网络针对 Peak Hours 和 Heavy Usage 进行监控与优化。

但消费者要注意：

“拥有自己的 Fibre 网络” ≠ “任何时候都不会塞车”。

Internet 最终仍然需要连接到其他网络、CDN、Data Centre、Peering 和 International Transit。

Allo：自己的 Fibre 基础设施，但采用 Open Access

Allo 又是另一种模式。

Allo 并不是单纯的 Retail ISP。它运营的是 Open Access Fibre Infrastructure，其他服务商也可以使用其网络。

Maxis 的网络资料也把 Allo 列为 Fibre network provider，并说明 Allo 是 TNB 的 Fibre network。

Source: Maxis — List of Providers

Maxis 官方网络提供商资料

Allo 官方的 Wholesale 页面则显示，其网络依托 TNB 的基础设施，并拥有约 25,000km TNB assets 的网络覆盖资源。

Source: Allo — Wholesale

Allo 官方 Wholesale 网络资料

所以 Allo 的重点在于：

Allo 自己建设/运营 Fibre 基础设施，同时允许其他服务商使用。

这和“一个 ISP 自己铺 Fibre、只卖给自己的客户”是不同商业模式。

为什么 Network Ownership 对 Peak Hours 有影响？

假设三个用户都是 500Mbps：

用户 A： ISP 使用 TM HSBA

用户 B： ISP 使用 TIME Fibre

用户 C： ISP 使用 Allo Fibre

白天进行 Speed Test，三个人都可能接近 500Mbps。

但到了晚上 9 点，体验可能开始出现差异。

原因是：

500Mbps 只是你家 Broadband Access 的速度。

它不代表整个 Internet Pathway 永远都有 500Mbps 的独享容量。

可以把它理解成高速公路：

你家 → Fibre Access → Aggregation → ISP Core → Internet Exchange / Peering → International Transit → 目标服务器

如果堵车发生在 ISP Core，换 TM / TIME / Allo 都不一定解决。

如果问题发生在 Access Network，那么拥有更多基础设施控制权的网络运营商就更容易直接进行 Network Upgrade 或 Capacity Management。

这才是 Network Ownership 真正重要的地方。

TIME 和 Allo 会不会完全没有 Peak-Hour Congestion？

不能这样保证。

TIME 官方确实强调其自有 Fibre 网络能够在 Peak Hours 和 Heavy Usage 下提供稳定表现。

Allo 也强调其网络基础设施、容量和稳定性，并在企业网络服务中提供高容量连接和 SLA。

Source: Allo — Wholesale

Allo 官方 Wholesale 网络资料

但消费者不要把这些理解成：

TIME = 永远不卡
Allo = 永远不卡
TM = 一定会卡

这三个结论都过度简化。

实际表现仍然取决于：

  1. Local Access Capacity
  2. Aggregation Capacity
  3. ISP Core Network
  4. International Bandwidth
  5. Peering
  6. CDN
  7. Routing
  8. Destination Server

为什么同一个 ISP，在不同地区表现可能不同？

因为 ISP 品牌不一定等于底层 Fibre 网络。

Maxis 官方资料目前就列出了多个 Fibre network providers，包括：

  1. TM-HSBA
  2. Allo
  3. TIME
  4. Maxis-NGBB
  5. 其他地区网络提供商

Source: Maxis — List of Providers

Maxis 官方 Fibre 网络提供商列表

所以如果你问：

“Maxis Fibre 好不好？”

其实还不够准确。

更有价值的问题应该是：

“我这个地址的 Maxis Fibre 是走哪一个底层网络？”

这也是为什么 Broadband 比较不能只看 ISP Logo。

所以真正的区别不是：

“谁的 500Mbps 比较快？”

而是：

“谁控制你家下面那条 Fibre，以及 ISP 如何把它连接到整个 Internet？”

消费者应该怎么选？

如果你的地址主要只有 TM HSBA

不代表不能选。

重点看：

  1. ISP 的 Peak-Hour 表现
  2. International Speed
  3. Gaming Latency
  4. Peering
  5. Customer Service
  6. Price
  7. Contract

如果 ISP 自己的网络容量规划做得好，TM HSBA 一样可以提供很好的体验。

如果 TIME 自有 Fibre 有覆盖

TIME 的优势在于其对 Access Network 拥有更高控制权。

对于：

  1. Gaming
  2. Cloud Backup
  3. Video Upload
  4. Work From Home
  5. 大量 Upload
  6. 家庭多设备使用

这类用户，可以把 TIME 纳入比较。

如果 Allo 网络覆盖

不要因为它是 Open Access 就直接认为性能差。

真正应该比较的是：

Allo Network + 具体 Retail ISP + Capacity + Routing

而不是只看 Allo 这个名字。

NetBijak's Take

不要只看 ISP Logo，也不要只看 Mbps。

真正值得问的是：

“我家使用哪一个 Fibre Network，以及这个 ISP 的上游容量和 Routing 怎么样？”

TM HSBA 的价值在于让不同 ISP 可以通过 TM 的 Fibre 基础设施提供服务，而不需要自己重新建设完整的 Access Network。

TIME 的优势则是拥有自己的 Fibre 网络，因此可以对更多底层网络环节进行控制。

Allo 则采取 Open Access 模式，运营基于 TNB 网络资源的 Fibre 基础设施，并向其他服务商开放。

但最终：

Network Ownership 只是影响 Broadband Experience 的其中一个因素。

真正决定你晚上 9 点能不能稳定使用 Internet 的，是：

Access Network + ISP Capacity + Peering + Routing + International Connectivity

所以以后比较 Malaysia Fibre，不要只问：

“100Mbps、300Mbps 还是 1Gbps？”

更专业的比较方式应该是：

Retail ISP → Underlying Fibre Network → Network Capacity → Peering/Routing → 实际体验

这才是 Fibre 套餐背后真正的差别。
