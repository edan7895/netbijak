什么是 Fibre Distribution Point（DP）箱？在马来西亚哪里可以找到？

✨ NetBijak AI 智能摘要

申请马来西亚家用光纤宽带时，了解Fibre Distribution Point（DP）箱的位置能极大提升安装效率。DP是光纤网络将信号从主干道延伸至住户的关键分配节点，其位置因建筑类型而异，常见于电线杆、地面箱体或公寓内部机房。住户无需自行检查设备，只需在安装人员询问时，提供DP箱上的编号、清晰的照片以及附近地标即可。请注意，附近的DP并不直接等同于你的地址一定具备光纤覆盖，具体安装条件仍需由专业技术人员实地评估。作为用户，切勿尝试打开或触碰这些基础设施，以免损坏网络连接。掌握这些基础知识，能帮你更从容地应对安装过程。

申请 Fibre 时，技术人员有时会问你：“DP 在哪里？”如果你连 DP 是什么都不知道，就很容易在现场花很多时间来回找。其实，你只需要知道 DP 的作用、常见位置，以及怎么把正确的位置告诉技术人员，就够了。

Fibre DP 到底是什么？

Fibre Distribution Point（DP），也常称为 Fibre Distribution Point（FDP），是 Fibre 接入网络中的一个分配节点，负责把 Fibre 网络连接延伸到客户住家。TM 的技术资料说明，FDP 用于连接 drop fibre 到客户 premises。

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

简单理解，可以把住家的 Fibre 路径看成：

Fibre Network → DP → Drop Fibre → 住家 → ONT/BTU → Router

实际网络结构会因地区、建筑和网络设计而不同，但对于一般用户来说，DP 就是“Fibre 从主网络分出来，往住家方向走”的重要节点。

1. 最容易看到的：电线杆上的 DP

在 landed property，例如 Terrace、Semi-D 或 Bungalow，最常见、也最容易看到的，是装在电线杆或通讯杆上的 Aerial DP。

TM 的技术资料直接列出 Aerial Fibre Distribution Point，并展示相关 Fibre distribution components。

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

Unifi 的官方安装指南也区分了 DP on the pole 的安装情况，并说明技术人员会根据 DP 的位置和布线条件决定安装方式。

(Source: Unifi — Installation Guide)

Unifi 官方安装指南

你在路边看到的，通常是一个固定在杆上的小型 Fibre 箱体，旁边会有 Fibre Cable 进出。

不要自己打开。

你真正需要记录的是 DP 的位置、标签和附近的明显地标。

2. 不是所有 DP 都挂在电线杆上

有些 Fibre DP 是设在地面上的。

TM 的技术资料列出多种 FDP 形式，包括：

  1. Aerial DP
  2. Underground DP
  3. Pedestal DP
  4. Wall-mounted DP

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

Unifi 的安装资料也明确提到 DP on the ground 的安装情形。

(Source: Unifi — Installation Guide)

Unifi 官方安装指南

所以，如果你在住宅区看到一个位于路边、地面或混凝土底座上的 Fibre Cabinet，不一定需要在电线杆上找。

不过，不要只凭箱子的颜色判断它是不是 Fibre DP。最可靠的方法是查看设备上的标签，再让技术人员确认。

3. 地下 DP：你可能根本看不到“箱子”

如果当地 Fibre Infrastructure 采用地下布线，DP 或相关 Fibre distribution infrastructure 可能不会以一个明显的地面箱体出现。

TM 的技术资料也列出 Underground DP。

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

这类情况下，你可能只看到：

  1. Telecommunications manhole
  2. Underground access cover
  3. 地面上的相关基础设施
  4. 通往住宅的地下 Fibre Route

所以：

看不到一个明显的 DP 箱，不代表你家附近没有 Fibre Distribution infrastructure。

尤其是 Apartment 和 Condo，更不能单纯靠“路边有没有一个箱子”来判断。

4. Condo / Apartment 的 DP 可能在哪里？

高楼住宅的情况通常比 landed house 复杂。

TM 的 FTTH 技术资料涵盖 High-Rise Building，以及 Riser、Riser Room、Telecommunications Room 等内部基础设施。

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

所以，在 Condo 或 Apartment，真正相关的 Fibre distribution point 不一定在大楼外面的马路边。

它可能和以下位置有关：

Riser → Telecommunications Room → MDF → Unit 内部 Fibre Point

具体安排取决于大楼本身的 Fibre Infrastructure。

因此，高楼住户找 DP 时，询问 Management Office / Building Management 往往比跑到大马路找绿色箱子更实际。

5. DP 箱上的编号到底怎么看？

很多人看到 DP 上有一串字母和数字，就会开始猜：

第一段是不是地区？
第二段是不是 Port？
后面是不是 House Number？

这里最容易出错。

不要自行假设 DP 编号有一个所有网络都通用的解码方式。

不同 Fibre Network 的标识方式可能不同。最安全的做法是：

整串号码原样记录，不要自己拆解。

例如看到：

ABC / 0123

不要直接把 ABC 解释成某个区域，也不要把 0123 当成 Port Number。

直接拍下来，给技术人员确认。

6. 最实用的方法：拍三张照片

如果技术人员叫你提供 DP 位置，最有用的不是长篇解释，而是照片。

第一张：拍清楚 DP Label

让编号完整可读。

第二张：拍整个 DP

让技术人员知道这是装在：

Pole / Ground / Wall / Pedestal

哪一种位置。

第三张：拍周围环境

把附近的：

  1. House Number
  2. Junction
  3. Street Sign
  4. Lamp Post
  5. 其他明显建筑

一起拍进去。

这样技术人员就不会只拿着一个编号，在整条街上找。

7. Landed House 要怎么找 DP？

如果你住的是 Terrace、Semi-D 或 Bungalow，可以先沿着住家外面的道路观察 Fibre Infrastructure。

重点看：

  1. 电线杆上的 Fibre Box
  2. 路边 Ground Cabinet
  3. Pedestal
  4. Fibre Cable Route
  5. 设备上的 Label

不过有一点很重要：

离你家最近的 DP，不一定就是服务你家的 DP。

真正决定连接关系的是 Fibre Route 和 Network Configuration，而不是单纯距离。

所以，如果看到两个 DP，不要自己判断“这个一定是我的”。

把两个位置拍下来，让技术人员确认更稳妥。

8. DP 在附近，是不是就一定能装 Fibre？

不一定。

附近有 DP，只能说明当地有相关 Fibre Infrastructure，并不能直接等于你的地址可以马上开通。

Unifi 的官方安装资料说明，安装人员需要根据 DP Location、房屋布局以及 Cabling Requirements 来判断合适的安装方式。

(Source: Unifi — Installation Guide)

Unifi 官方安装指南

所以这两个概念不要混在一起：

DP 在附近 ≠ 一定可以安装

Fibre Coverage ≠ 一定有可立即使用的连接

是否能够安装，还需要看具体地址、网络条件和实际安装路线。

9. 为什么技术人员那么在意 DP 在哪里？

因为 DP 是实际 Fibre 路线的一部分。

例如 Unifi 的安装资料就区分：

DP 在 Pole → 直接往屋墙入口布线

以及涉及其他 Cable Routing 的安装方式。

(Source: Unifi — Installation Guide)

Unifi 官方安装指南

所以技术人员不是单纯想知道“哪个箱子长得像 Fibre Box”，而是需要判断：

DP 在哪里 → Cable 怎么走 → 怎样进入你的房子

这也是为什么安装前拍清楚 DP，会比只告诉客服“附近有 Fibre Box”有用很多。

10. 不要自己打开 DP

DP 是 Network Infrastructure，不是用户可以自己检查的设备。

不要：

  1. 打开箱子
  2. 拔 Fibre Connector
  3. 拉 Fibre Cable
  4. 移动设备
  5. 自己检查 Port
  6. 尝试追踪哪一条 Fibre 属于哪一家住户

TM 的技术资料显示 FDP 内部包含 Fibre Distribution Components，包括 Adaptor Panel、Optical Splitter 和 Fibre Organiser 等。

(Source: TM — Fibre Distribution Point / Self Learning Notes)

TM 官方 Fibre 技术资料

你作为住户真正需要做的，其实只有：

找到 → 拍照 → 记录位置 → 告诉技术人员。

NetBijak’s Take

找 Fibre DP 不需要你变成 Fibre Technician。

对普通住户来说，最有用的就是记住三件事：

看位置、拍编号、留地标。

尤其是同一条路上有多个 Fibre Box 时，“DP 编号 + 清楚照片 + 附近地标” 会比一句“DP 在我家附近”有用得多。
