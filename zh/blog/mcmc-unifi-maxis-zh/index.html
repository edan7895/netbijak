MCMC 审查 MSAP，Unifi 与 Maxis 再度过招！未来马来西亚家用光纤会更便宜吗？

MCMC 审查 MSAP，马来西亚家用 Fibre 宽频会迎来新一轮价格战吗？

马来西亚宽频用户近期可能需要关注一个重要变化——马来西亚通讯及多媒体委员会（MCMC）正在推进新一轮 Mandatory Standard on Access Pricing（MSAP）相关审查。

MSAP 是马来西亚电信行业的重要监管机制之一，主要涉及部分电信设施及服务的批发接入价格。

简单来说，消费者每个月支付的 Fibre 宽频费用，并不只是网络本身的成本。宽频供应商如果需要使用其他运营商的网络基础设施，就可能涉及批发接入费用。

因此，批发价格的变化，有可能进一步影响消费者最终看到的零售宽频价格。

2023 年实施的上一轮 MSAP 就曾明显降低部分受监管的 HSBB 批发接入价格，目标之一就是推动更具竞争力的宽频市场。(The Edge Malaysia⁠)

为什么 MSAP 会影响普通消费者？

消费者不会直接看到 MSAP 批发价格。

但是，如果宽频供应商的网络成本下降，理论上就可能拥有更多空间：

  1. 降低每月宽频收费
  2. 在相同价格提供更高速度
  3. 推出更多促销
  4. 提供更好的设备
  5. 加强市场竞争

不过需要注意：

批发价格下降，并不代表零售价格一定会等比例下降。

供应商还需要考虑网络维护、客服、设备、营销、安装和利润等成本。

Unifi 与 Maxis 为什么特别值得关注？

在马来西亚家用 Fibre 市场中，TM 的 Unifi 和 Maxis 都是重要的主要参与者。

Unifi 背后拥有 TM 的大型 Fibre 网络基础设施，而 Maxis 过去也通过不同的网络安排和商业合作参与 Fibre 市场竞争。

过去的 MSAP 调整就曾对市场产生影响。

例如在 2023 年 MSAP 之后，Maxis 调整了 Home Fibre 的价格。100Mbps 配套当时调整至 RM99/月，而 300Mbps、500Mbps 等速度的价格也变得更加具有竞争力。(SoyaCincau⁠)

这说明：

监管批发价格变化 → 供应商成本变化 → 市场竞争 → 消费者价格/速度可能变化

但中间并不是简单的一步到位。

新一轮 MSAP 会让 Fibre 更便宜吗？

有可能，但目前还不能保证。

2026 年的行业分析认为，新一轮 MSAP 审查可能带来更低的批发宽频接入价格，并可能在 2026 年底前逐步落实。

不过，也有分析指出，供应商不一定会把所有成本节省直接转嫁给消费者。一部分节省可能用于改善利润率或其他网络投资。(MalaysianWireless⁠)

因此，消费者未来可能看到几种不同结果。

情况一：月费直接下降

例如：

RM139 → RM129

供应商通过降低月费吸引新客户。

情况二：价格不变，但速度升级

这其实可能是消费者非常期待的情况。

例如：

RM139

300Mbps → 500Mbps

马来西亚过去的宽频市场就曾出现过监管调整后，供应商提高速度或推出更具竞争力配套的情况。(Scribd⁠)

情况三：促销变得更加激烈

供应商可能不直接降低标准价格，而是推出：

  1. 免费安装
  2. Cashback
  3. 免费 WiFi Router
  4. 免费几个月
  5. 免费 Speed Upgrade
  6. Mesh WiFi 优惠

对于消费者来说，这些优惠同样可能降低实际使用成本。

Unifi 会不会降价？Maxis 会不会跟？

这可能是消费者最想知道的问题。

答案是：

现在还不能确定。

MSAP 主要影响的是受监管的批发接入价格，并不是直接规定：

「Unifi 必须卖 RM99。」

最终零售价格仍然取决于供应商的商业策略。

如果 Unifi 降价，Maxis 可能需要跟进。

如果 Maxis 推出更具吸引力的高速配套，Unifi 也可能通过速度升级或促销回应。

因此，真正可能发生的并不是简单的「Unifi vs Maxis」，而是整个 Fibre 市场的竞争进一步加剧。

那现在应该等降价，还是马上申请？

如果你现在正需要 Fibre 宽频，不建议单纯因为 MSAP 审查就无限期等待。

因为宽频供应商本身就会不定期推出促销。

申请之前，可以比较：

  1. 每月价格
  2. Download Speed
  3. Upload Speed
  4. 合约期限
  5. 安装费用
  6. Router / Mesh
  7. Cashback
  8. 免费升级
  9. 实际使用需求

如果现在有非常好的 Promotion，未必一定要等到 MSAP 完全落实之后才申请。

2026 年马来西亚 Fibre 宽频可能出现什么变化？

未来最值得期待的，可能不只是：

「宽频降价」

而是：

更低价格 + 更高速度 + 更多优惠

上一轮 MSAP 已经证明，监管政策可以影响 Fibre 宽频市场的竞争。

而新一轮 MSAP 如果进一步降低批发接入成本，供应商之间的竞争可能再次加剧。

对于消费者来说，这反而是一件好事。

因为最终决定权还是回到消费者手上：

比较更多配套，再选择最适合自己的宽频。
