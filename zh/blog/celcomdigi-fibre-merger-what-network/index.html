CelcomDigi Fibre 合并：网络整合会怎样影响用户？

✨ NetBijak AI 智能摘要

CelcomDigi的合并主要集中在移动网络整合，家庭光纤网络的情况则更为复杂，并不仅是两家公司线路的简单合并。该公司目前通过自有的基础设施以及如TIME等合作伙伴的网络，共同提供家庭光纤覆盖。用户需要明确区分账单调整、套餐迁移和搬家迁机这三种不同情况对合约的影响。账单系统调整通常不会改变现有合约，而搬家迁机则极大概率会产生额外费用并重新签署合约。覆盖地图显示可用并不等同于实地拥有空闲端口，实际安装还需视现场情况而定。用户在处理相关业务时，应关注具体的条款变更，而非仅仅担心“合并”带来的未知影响。

Celcom 和 Digi 在 2022 年 12 月完成合并，之后 CelcomDigi 开始整合两家公司的网络和系统。(CelcomDigi)

但对于家庭 Fibre 用户来说，“网络整合”不能简单理解为：

旧 Celcom Fibre + 旧 Digi Fibre = 一套新的实体 Fibre Network

实际情况复杂得多。CelcomDigi Fibre 除了自身的 Fibre Infrastructure，也使用其他基础设施伙伴，例如 TIME 的 Fibre Network。(CelcomDigi)

合并后整合的重点，不只是 Fibre

CelcomDigi 在合并后的大型 Network Integration Programme，主要针对 Celcom 和 Digi 的 Mobile Network。

公司公布的整合计划涉及大量 Celcom 和 Digi 原有的网络站点，包括升级、整合以及移除重复的网络设施。CelcomDigi 在 2026 年表示，计划中的 Network Integration and Modernisation 已完成，并进入最后阶段的 IT Consolidation。(CelcomDigi)

所以不能把 Mobile Network Integration 直接等同于：

“两家公司的住宅 Fibre Network 已经物理合并成一张网。”

家庭 Fibre 的情况还要看实际提供服务的基础设施。

为什么 CelcomDigi Fibre 可能使用其他公司的 Fibre？

一个很明显的例子就是 TIME。

CelcomDigi 在 2023 年宣布与 TIME 合作，让 CelcomDigi 使用 TIME 的 Fibre Broadband Infrastructure 扩大家庭 Fibre 覆盖，尤其是 Condominium 和 Apartment。(CelcomDigi)

这意味着：

CelcomDigi Fibre 用户 ≠ 一定使用 CelcomDigi 自己铺设的最后一公里 Fibre。

用户看到的是 CelcomDigi 的零售服务，但实际 Fibre Infrastructure 可能来自合作伙伴。

账单改变，不等于 Fibre 合约改变

2026 年 8 月，CelcomDigi 开始把部分 Combined Billing Account 分开处理。

CelcomDigi 明确说明，这项调整 不需要重新申请 Fibre，也不需要重新签约。现有的套餐、合约期限、月费和 Internet Speed 都保持不变，改变的只是账单结构和付款方式。(CelcomDigi Help Centre)

所以要区分：

Billing Migration ≠ Fibre Migration ≠ New Contract

如果只是账户或账单系统调整，不应该直接理解为 Fibre 线路已经换了，或者合约重新开始计算。

套餐迁移又是另一回事

CelcomDigi 后来也提供不同的 Fibre 与 Mobile Bundle。

例如符合条件的用户改用 CelcomDigi One 配套时，原有 Fibre Plan 可能被调整到符合资格的 Fibre Plan。(CelcomDigi Help Centre)

但这里有一个重要区别：

套餐改变 ≠ 因为 Celcom-Digi 合并而自动重新签 24 个月合约。

CelcomDigi 目前也明确说明，Fibre Contract 和 CelcomDigi Postpaid 5G Contract 是两个独立合约。(CelcomDigi Help Centre)

所以用户收到 Package Migration 通知时，应该检查的是具体的 Plan Change 条件，而不是单纯看“CelcomDigi Merger”。

搬家才可能明确产生新的 24 个月合约

Relocation 是另外一种情况。

CelcomDigi 现行 Fibre Relocation 条款写明：

如果新地址在 Fibre Coverage 内，而且有可用 Port，Relocation Fee 为 RM200；完成安装后会开始一个新的 24 个月合约。(CelcomDigi Help Centre)

而且：

Coverage ≠ Port Availability

CelcomDigi 会在新地址属于覆盖范围后，继续检查实际 Fibre Port 是否可用。(CelcomDigi Help Centre)

这对用户非常重要。

地图显示有 Fibre，并不代表你的具体 Unit、House 或 Apartment 已经有空闲 Port。

为什么 Coverage Map 会重叠？

CelcomDigi、TIME 或其他 Fibre Provider 的 Coverage Map 出现重叠，并不代表同一条路下面一定铺了两套完全独立的 Fibre Cable。

Coverage Map 主要显示：

这个地区是否可以购买这项服务。

它不一定告诉你：

最后一公里 Fibre 到底是谁拥有。

CelcomDigi 使用 TIME Fibre Infrastructure 就是很直接的例子。一个 CelcomDigi Fibre 产品，可以利用其他运营商已经存在的 Fibre Infrastructure 提供服务。(CelcomDigi)

所以看到两个 Provider 都显示“Available”，不要马上理解成：

“这里有两套 Fibre Network。”

更实际的问题是：

“我的具体地址有没有 Fibre Port？”

以及：

“这条 Fibre 实际使用哪一个 Infrastructure？”

整合期间用户真正需要注意什么？

只是 Billing Change

如果只是账单账户被分开，CelcomDigi 已明确表示现有 Plan、Speed、Monthly Fee 和 Contract Terms 不变，也不需要重新签约。(CelcomDigi Help Centre)

更换 CelcomDigi 配套

检查新的 Fibre Plan 是否改变月费、Rebate 或 Contract Conditions。

CelcomDigi 现行资料也明确把 Fibre Contract 与 Mobile Contract 分开计算。(CelcomDigi Help Centre)

Fibre Relocation

这里就要特别注意。

成功搬迁后会产生 RM200 Relocation Fee，并重新开始 24 个月 Fibre Contract；如果新地址需要 Non-standard Installation 或额外 Cabling，承包商还可能另外收费。(CelcomDigi Help Centre)

NetBijak’s Take

Celcom 和 Digi 合并，并不等于两套住宅 Fibre Network 简单合成一套。CelcomDigi Fibre 本身也可以使用 TIME 等合作伙伴的 Fibre Infrastructure。对于用户来说，真正需要分清的是 Billing Change、Package Migration 和 Relocation：它们对合约的影响不同，而 Coverage Map 重叠也不代表你的地址一定有两个独立 Fibre Port。
