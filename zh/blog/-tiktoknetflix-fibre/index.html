孩子一直刷 TikTok，Netflix 一直卡？先别急着升级 Fibre

✨ NetBijak AI 智能摘要

当家里出现网络卡顿时，不应盲目升级宽带配套，因为问题往往源于网络拥塞或WiFi干扰。首先，建议将电视等固定设备改为有线连接，以避开无线干扰。同时应检查是否有设备在后台自动更新或进行高流量备份，抢占了网络带宽。如果路由器支持流量管理，可开启QoS功能优先保障电视的网络需求。此外，确保路由器位置摆放正确且覆盖范围足够，能有效提升家中网络的实际表现。只有在排除了上述因素并确认网络速度确实无法满足家庭需求时，才考虑升级更高规格的宽带套餐。

为什么孩子刷 TikTok，Netflix 就开始卡？

如果孩子一刷 TikTok，你的 Netflix 就开始 Buffer，先不要急着升级 Fibre 配套。

问题可能是家里的 网络拥塞、WiFi 干扰或 Router 性能，不一定是你订的 Fibre Mbps 不够。

现在马来西亚很多家庭同时连接大量设备。Maxis 也指出，多台设备同时连接及高带宽活动会影响家里的网络体验。 (Maxis⁠)

先试这 5 个方法

1. TV 尽量用 LAN Cable

如果 TV 或 TV Box 靠近 Router，尽量使用 Ethernet LAN Cable。

有线连接不会受到许多 WiFi 距离和无线干扰问题影响。Maxis 也建议需要稳定表现的设备，例如 Streaming Device 和 Gaming Console，使用有线连接。 (Maxis⁠)

2. 检查谁正在抢网络

Netflix 卡的时候，看看 Router 里面到底有哪些设备正在使用网络。

常见的网络流量来源包括：

  1. TikTok、YouTube 和短视频
  2. iCloud 或 Google Photos 自动备份
  3. 大型游戏下载
  4. Windows、手机或 App 自动更新
  5. 多台 TV 同时 Streaming
  6. CCTV 上载录像

有时候问题只是短时间的网络流量突然增加，而不是 Fibre 配套不够快。

3. 使用 QoS 或 Device Priority

如果你的 Router 支持 QoS、Device Priority 或类似的流量管理功能，可以把 TV 或 Streaming Device 设为优先。

这样当其他设备大量使用网络时，Router 可以优先处理电视的网络流量。

不过，不同 Router 的功能不同，不要假设所有 Unifi、Maxis 或 TIME 提供的 Router 都有一样的 QoS 设置。

4. 先解决 WiFi，再怪 Fibre

Fibre 很快，不代表 WiFi 一定快。

Maxis 指出，Router 摆放位置、连接设备数量、厚墙以及附近无线网络干扰，都可能影响实际 WiFi 表现。 (Maxis⁠)

可以尝试：

  1. 把 Router 放在屋子中央、较开放的位置
  2. 不要放在厚墙或大型电器旁边
  3. Router 支持的话使用 5GHz 或 6GHz WiFi
  4. 大房子考虑正确摆放的 Mesh WiFi
  5. TV 等固定设备尽量使用 LAN

5. 什么情况下才应该升级 Fibre？

只有当你的 Fibre 本身真的成为瓶颈时，才需要考虑升级。

Maxis 目前按照家庭使用情况建议不同速度，例如 100Mbps 面向 2–3 台设备、300Mbps 面向 4–5 台、500Mbps 面向 6–8 台，以及 1Gbps 面向 8–10 台连接设备。 (Maxis⁠)

这些是 ISP 的建议，不是技术上的绝对限制。

如果你的 100Mbps 在 TV 使用 LAN 时完全正常，只是某个房间 WiFi 不稳定，那么升级到 500Mbps 很可能解决不了真正的问题。

升级前做一个简单测试

Netflix 卡的时候：

Step 1： 用 LAN 测试网络速度。

Step 2： 再用 WiFi 测试同一个网络。

Step 3： 暂停 TikTok、游戏下载和 Cloud Backup。

Step 4： 看 Netflix 是否恢复正常。

如果暂停其他高流量活动后 Netflix 就稳定了，你的 Fibre 本身可能不是主要问题。

NetBijak Tips

更快的 Fibre，不一定等于更好的家庭网络。

升级 100Mbps 到 300Mbps 或 500Mbps 前，先检查 WiFi Coverage、Router 和家里多人同时使用网络的情况。有时候不用换更贵的配套，也能解决 Netflix 卡顿问题。
