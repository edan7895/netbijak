隐私政策

1. 概述

NetBijak（"我们"）重视您的隐私权。本隐私政策旨在说明我们在您访问本网站时如何收集、使用和保护您的个人信息。我们严格遵守马来西亚《2010年个人资料保护法》（PDPA）。

2. 我们收集的信息

日志与分析数据：我们通过 Google Analytics 等工具收集标准的浏览器访问数据（如 IP 地址、浏览器类型、浏览页面及停留时间），用于优化网站体验。

Cookie 技术：我们使用必要的 Cookie 来改善网站导航并分析流量来源。

直接联系信息：当您通过电子邮件或 WhatsApp 主动联系我们时，我们会保留您提供的联系方式以回复您的问询。

3. 第三方及电信运营商链接

本站包含指向第三方网站（如 TM、Maxis、Time、CelcomDigi 等）的外链。我们不对这些外部网站的隐私条款或内容承担法律责任。

4. 数据安全

我们采用行业标准的安全措施，防止您的个人数据遭遇未经授权的调阅、泄露或修改。
