TM HSBA vs TIME vs Allo: Memahami Perbezaan Rangkaian Fibre Shared dan Owned

✨ Ringkasan AI NetBijak

Memilih pelan internet jalur lebar bukan sekadar melihat kelajuan Mbps, kerana kualiti sambungan sangat bergantung kepada penyedia rangkaian di sebalik ISP tersebut. Terdapat perbezaan ketara antara model rangkaian seperti TM HSBA yang bersifat borong, rangkaian milik sendiri oleh TIME, dan model akses terbuka oleh Allo. Walaupun rangkaian milik sendiri menawarkan kawalan infrastruktur yang lebih baik untuk pengurusan kapasiti, ia bukan jaminan mutlak untuk mengelakkan kesesakan trafik pada waktu puncak. Pengalaman internet yang lancar sebenarnya melibatkan rantaian yang kompleks, merangkumi kapasiti rangkaian akses, teras ISP, serta kualiti hubungan antara rangkaian antarabangsa. Oleh itu, pengguna dinasihatkan untuk memahami bahawa kesesakan boleh berlaku pada mana-mana titik laluan data, tidak kira sama ada rangkaian tersebut dimiliki oleh ISP itu sendiri atau disewa daripada pihak lain. Memahami perbezaan ini membantu pengguna membuat keputusan yang lebih bijak berdasarkan ketersediaan infrastruktur di lokasi masing-masing.

TM HSBA vs TIME vs Allo: Memahami Perbezaan Rangkaian Fibre Shared dan Owned

SEO Title: TM HSBA vs TIME vs Allo: Shared vs Owned Fibre Network di Malaysia

SEO Description: Apa beza TM HSBA, TIME dan Allo Fibre? Fahami bagaimana Wholesale Fibre, rangkaian sendiri, kapasiti Peak Hours dan routing boleh mempengaruhi pengalaman Internet anda di Malaysia.

Kalau dua pelan Fibre menawarkan 500Mbps, itu tidak bermaksud kedua-duanya akan memberikan pengalaman Internet yang sama.

Salah satu sebabnya ialah rangkaian Fibre di belakang ISP tersebut mungkin berbeza.

Di Malaysia, anda akan jumpa beberapa model seperti TM HSBA, TIME own Fibre network dan Allo open-access Fibre network.

Jadi sebelum pilih pelan, jangan tengok Mbps sahaja.

Soalan yang lebih penting ialah:

“Siapa yang memiliki dan mengendalikan rangkaian Fibre yang sampai ke rumah saya?”

Apa Itu TM HSBA?

HSBA (High-Speed Broadband Access) ialah perkhidmatan akses rangkaian secara Wholesale yang disediakan oleh Telekom Malaysia.

Mudah cerita, ISP lain boleh menggunakan infrastruktur Fibre TM untuk menyediakan perkhidmatan Broadband kepada pelanggan tanpa perlu membina keseluruhan rangkaian Fibre sendiri.

Maxis sendiri menyenaraikan TM-HSBA, Allo dan TIME sebagai antara network providers dalam ekosistem Fibre mereka.

Source: Maxis — List of Providers

Senarai network provider rasmi Maxis

Sebab itu, apabila anda langgan Fibre daripada sesuatu ISP, nama ISP tersebut tidak semestinya bermaksud mereka memiliki Fibre network yang sampai ke rumah anda.

Bergantung pada alamat, ISP yang sama boleh menggunakan network provider yang berbeza.

TM HSBA Bermaksud Internet Akan Slow Waktu Malam?

Tidak semestinya.

Ini perkara paling penting untuk difahami.

Memang mudah untuk membuat kesimpulan:

TM wholesale → ramai ISP guna → Peak Hours mesti congested.

Tetapi struktur Internet sebenar jauh lebih kompleks.

Sambungan Fibre anda boleh dibayangkan seperti ini:

Rumah → Access Network → Aggregation → ISP Core → Peering / Internet Exchange → International Network → Website / Game Server / Streaming

Kalau congestion berlaku di mana-mana bahagian ini, pengalaman Internet boleh terjejas.

Contohnya:

  1. Access Network kurang capacity
  2. Aggregation network congested
  3. ISP Core tidak mempunyai capacity yang mencukupi
  4. International transit penuh
  5. Routing kurang baik
  6. Peering bermasalah
  7. CDN atau server tertentu mengalami masalah

Jadi, jangan terus salahkan TM HSBA apabila Internet slow waktu malam.

Sebaliknya, Fibre network milik sendiri pun tidak bermaksud ISP tersebut mustahil mengalami congestion.

TIME: Fibre Network Sendiri

TIME menggunakan model yang berbeza di kawasan yang mempunyai coverage mereka.

TIME menyatakan bahawa mereka memiliki 100% Fibre network sendiri untuk perkhidmatan Home Fibre.

TIME juga menyatakan bahawa mereka mempunyai kawalan penuh terhadap rangkaian tersebut.

Source: TIME — Our Fibre Network

TIME rasmi — Our Fibre Network

Maklumat korporat TIME turut menerangkan bahawa rangkaian Fibre mereka dibina di sekitar Cross Peninsular Cable System (CPCS).

Source: TIME — Who We Are

TIME rasmi — Who We Are

Kelebihan utama di sini ialah network control.

TIME mempunyai lebih banyak kawalan terhadap:

  1. Fibre Access Network
  2. Network Capacity
  3. Network Upgrade
  4. Fault Management
  5. Network Engineering
  6. Network Optimisation

TIME juga secara rasmi menyatakan bahawa rangkaian mereka dipantau dan dioptimumkan untuk memberikan prestasi yang konsisten ketika Peak Hours atau Heavy Usage.

Tetapi jangan salah faham.

Own network tidak bermaksud Internet akan sentiasa laju tanpa sebarang congestion.

Traffic anda masih perlu melalui network lain untuk sampai ke Netflix, YouTube, game server, cloud platform atau website luar negara.

Allo: Own Infrastructure Tetapi Open Access

Allo pula menggunakan model yang sedikit berbeza.

Allo bukan sekadar Retail ISP. Ia juga merupakan Fibre infrastructure provider yang menggunakan model Open Access.

Ini bermaksud ISP lain boleh menggunakan network Allo untuk memberikan perkhidmatan kepada pelanggan mereka.

Maxis secara rasmi menyenaraikan Allo sebagai salah satu Fibre network provider.

Source: Maxis — List of Providers

Maxis rasmi — List of Providers

Allo pula menyatakan bahawa rangkaian mereka menggunakan aset TNB yang luas, dengan sekitar 25,000km TNB assets dalam footprint rangkaian mereka.

Source: Allo — Wholesale

Allo rasmi — Wholesale Services

Jadi model Allo boleh difahami sebagai:

Allo membina dan mengendalikan Fibre infrastructure, kemudian membuka rangkaian tersebut kepada service providers lain.

Ini penting kerana:

“Owned network” dan “Wholesale network” bukan semestinya dua perkara yang bertentangan.

Sebuah network owner seperti Allo boleh pada masa yang sama menjadi Wholesale network provider.

Kenapa Network Ownership Penting Ketika Peak Hours?

Bayangkan tiga pelanggan mempunyai pelan 500Mbps.

Pelanggan A: ISP menggunakan TM HSBA

Pelanggan B: ISP menggunakan TIME Fibre

Pelanggan C: ISP menggunakan Allo Fibre

Pada waktu siang, ketiga-tiganya mungkin mendapat speed test yang hampir sama.

Tetapi pada pukul 9 malam, pengalaman mereka boleh berbeza.

Kenapa?

Sebab 500Mbps ialah access speed anda, bukan jaminan bahawa setiap bahagian Internet Pathway mempunyai 500Mbps capacity untuk anda.

Secara mudah:

Rumah → Fibre Access → Aggregation → ISP Core → Peering → International Transit → Server

Jika congestion berlaku di ISP Core, menukar Fibre Access Network sahaja mungkin tidak menyelesaikan masalah.

Tetapi jika masalah berlaku pada Access Network, network owner yang mempunyai kawalan lebih besar terhadap infrastructure mempunyai lebih banyak ruang untuk melakukan upgrade dan capacity planning.

Di sinilah kelebihan network ownership menjadi penting.

Adakah TIME dan Allo Tidak Akan Congested?

Tidak boleh dijamin begitu.

TIME memang menyatakan bahawa rangkaian Fibre mereka dioptimumkan untuk memberikan prestasi yang konsisten ketika Peak Hours.

Allo pula menekankan kapasiti, resilience dan prestasi rangkaian dalam perkhidmatan Wholesale mereka.

Source: Allo — Wholesale

Allo rasmi — Wholesale Services

Tetapi pengguna tidak patut menukar fakta ini menjadi:

TIME mesti sentiasa laju.
Allo mesti sentiasa laju.
TM mesti selalu congested.

Semua itu terlalu simplistik.

Prestasi sebenar bergantung kepada:

  1. Local Access Capacity
  2. Aggregation Capacity
  3. ISP Core Network
  4. International Bandwidth
  5. Peering
  6. CDN
  7. Routing
  8. Destination Server

Jangan pilih Fibre hanya berdasarkan logo ISP atau angka Mbps.

Soalan yang lebih penting ialah:

“Untuk alamat saya, siapa yang memiliki Fibre network dan bagaimana ISP tersebut mengurus upstream capacity serta routing?”

TM HSBA memainkan peranan penting kerana ia membolehkan pelbagai ISP menggunakan infrastruktur Fibre TM tanpa perlu membina keseluruhan access network sendiri.

TIME pula mempunyai kelebihan dari segi kawalan kerana ia memiliki Fibre network sendiri.

Allo menggunakan pendekatan Open Access, di mana mereka mengendalikan Fibre infrastructure dan membuka rangkaian tersebut kepada service providers lain.

Tetapi akhirnya:

Network ownership bukan satu-satunya faktor yang menentukan Internet Experience.

Prestasi anda lebih bergantung kepada gabungan:

Access Network + ISP Capacity + Peering + Routing + International Connectivity

Jadi apabila membandingkan Fibre di Malaysia, jangan berhenti pada:

100Mbps vs 300Mbps vs 1Gbps.

Lihat keseluruhan perjalanan sambungan:

Retail ISP → Underlying Fibre Network → Network Capacity → Peering/Routing → Actual User Experience
