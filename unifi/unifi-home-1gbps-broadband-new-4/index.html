Performance & MCMC 90% Benchmark

Unifi specifies up to 1Gbps download and 500Mbps upload for the FTTR plan.

Using the commonly referenced 90% fixed-broadband throughput benchmark:

1,000Mbps × 90% = 900Mbps

So 900Mbps is the useful reference point when checking a gigabit fibre connection under controlled testing conditions.

For upload:

500Mbps × 90% = 450Mbps

A proper speed test should therefore be performed using a capable wired device where possible.

For the most meaningful test:

  1. Connect directly to the router using Gigabit Ethernet or faster.
  2. Use a Cat5e/Cat6 cable.
  3. Make sure the computer's network adapter supports Gigabit Ethernet.
  4. Stop other heavy network activity.
  5. Run several tests against reliable nearby test servers.

A Wi-Fi result should not automatically be treated as proof that the fibre connection is underperforming. Wireless performance depends on the client device, distance, interference and the radio environment inside the home.

Hardware & Technical Traps

At 1Gbps, the network equipment becomes much more important.

Gigabit Ethernet Is Essential

A device with only a 100Mbps Ethernet port cannot make full use of a 1Gbps connection.

The same applies to older switches, access points and adapters. The fibre connection can be delivering gigabit speeds while an individual device remains limited by the slowest component in its network path.

For wired connections, Gigabit Ethernet should therefore be considered the minimum.

Cat5e is normally sufficient for Gigabit Ethernet, so there is no automatic need to replace working home cabling simply because you upgraded to 1Gbps.

Wi-Fi 6 Helps, But It Does Not Guarantee 1Gbps

The FTTR package uses a Wi-Fi 6 Main Hub and Wi-Fi 6 Mesh Satellite Hub.

This is useful for distributing wireless connectivity around the home, but Wi-Fi 6 itself does not guarantee that a phone or laptop will record 900Mbps+.

Actual wireless speed depends on:

  1. Client device capability
  2. Number of spatial streams
  3. Channel conditions
  4. Distance from the access point
  5. Wall construction
  6. Interference from neighbouring networks

A Wi-Fi 6 router paired with an older Wi-Fi client can still produce much lower speeds.

FTTR Is About Coverage, Not Extra Internet Speed

This distinction is important.

The Satellite Hub does not turn 1Gbps into more than 1Gbps. Its purpose is to bring the network closer to areas where the main router would otherwise provide weaker wireless coverage.

The FTTR design uses internal fibre wiring to connect the equipment, and Unifi says the installation can be done without hacking through walls.

For a home with multiple rooms or difficult coverage areas, this can be more useful than simply buying a faster broadband plan.

1Gbps vs 500Mbps: What Are You Actually Paying For?

The jump from 500Mbps to 1Gbps is a 2× increase in download capacity, but that does not mean every online activity becomes twice as fast.

The difference is most obvious when transferring large amounts of data.

For example, downloading a very large game or transferring a large work file can benefit from the additional bandwidth if the remote server and local equipment can also sustain those speeds.

For normal web browsing, social media, video calls and standard streaming, the improvement may be difficult to notice.

This is why a 1Gbps plan should not automatically be considered a better choice simply because the advertised speed is higher.

Where the FTTR Setup Makes More Sense

The strongest reason to consider this particular 1Gbps package is the combination of gigabit bandwidth and distributed home networking.

It becomes more interesting when:

  1. The main router cannot provide consistent coverage throughout the house.
  2. Important rooms are far from the main router.
  3. You want wired-quality backhaul without relying entirely on wireless mesh links.
  4. Several parts of the house require stable high-speed Wi-Fi.
  5. Your main devices already support Wi-Fi 6 or Gigabit Ethernet.

This makes the FTTR component more relevant than simply looking at the 1Gbps number.

Address-Level Reality

The plan is still subject to TM infrastructure readiness and availability at the installation address. Unifi's FTTR terms also state that the service is provided on a best-effort basis and recommend compatible devices capable of supporting the bandwidth.

For landed properties, condominiums and older buildings, do not assume that an advertised 1Gbps plan automatically means the same installation setup is available at every unit.

Check the exact address before comparing plans based solely on the advertised speed.

Who Should Get Unifi Home 1Gbps?

Consider it if you:

  1. Need gigabit-class broadband for large data transfers.
  2. Have modern Wi-Fi 6 or Gigabit-capable devices.
  3. Have a larger home with difficult Wi-Fi coverage.
  4. Want fibre-based distribution between network points.
  5. Regularly upload large files or perform cloud backups.
  6. Already find 500Mbps sufficient but want more headroom for demanding transfers.

Consider 500Mbps instead if you:

  1. Mainly browse, stream and make video calls.
  2. Rarely download or upload very large files.
  3. Have older Wi-Fi devices.
  4. Do not have a coverage problem in your home.
  5. Would not use the additional gigabit capacity regularly.
